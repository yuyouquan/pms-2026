# 基础信息补全待办验收

## 行为

- 工作台任务目录按“基础信息、计划、转维”排序，优先展示首个有待处理任务的分类。
- 按项目责任人和基础信息查看、编辑权限生成个人待办，每人每项目一条；展示保存记录中的缺失必填项。
- 正式项目复用原创建表单的可填写必填字段和条件规则；只读来源、派生字段不单独生成无法填写的任务。预算项目按项目类型提醒，保留分次补充能力。
- 路标项目沿用原待规划创建表单的必填项，包含二级分类、安卓版本、产品类型、tOS、品牌、产品线、产品系列、市场名、芯片、RAM、版本类型、开发模式和两项日期。
- “去填写”按项目 ID 进入基础信息并打开现有编辑弹窗；导航意图绑定用户、项目且消费一次，返回时清理。
- 取消或部分保存保留剩余待办，全部补齐后移除；删除项目或变更责任人、权限后重新计算。
- 能力建设项目没有额外的类型必填字段，不人为增加要求。
