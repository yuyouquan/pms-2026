# 项目资源看板验收

## 数据口径

- 年度预算、项目概算、项目预算分别默认唯一正式版本；没有正式版本或存在冲突时不自动回退。用户可选择其他可读版本分析，不修改正式状态。
- 三类预算独立比较，不叠加。关联年度预算遵循项目绑定和用户权限。
- 年份、二级部门和详细分析分类联动；费用为人月乘配置费率，加非人力元金额除以 10000。
- 部门平衡按来源行检查，同名行不足/超额分别保留；目标缺行与历史明细缺失均提示。
- 趋势支持人月/万元、月度/所选期间累计；时间轴保留间断月份，缺失值不当零。导出七个工作表，包含当前趋势口径。

## 第一轮

- 新增数据脚本：手工跨年数据、部门筛选、费用单位、四类项目来源、绑定与权限、分析不写回。
- `npx tsc --noEmit --pretty false` 和 `npm run build` 通过。
- `verify:resource-inline`、`verify:resource-versions`、`verify:resource-formal` 通过。
- 独立审查发现并修正：空年份图表假零、部门筛选日期提示泄漏、累计导出不匹配、同名来源行偏差抵消、部分缺行及旧版本明细缺失误报平衡。
