# 项目空间资源改造验收记录

日期：2026-09-20。功能分支：`codex/feature-project-auto-scheduling`。实现依据：[18 项需求设计](../superpowers/specs/2026-09-20-resource-formal-version-workspace-design.md)。

## 已确认规则

- 阶段比例允许逐格暂存，行合计必须为 100% 才能设置正式版本。
- 月度投入允许逐月修正，已分配合计显示规定值及正负差额；各部门全周期月度合计必须等于部门预估投入才能设置正式版本。
- 能力建设没有细分阶段配置，使用“项目周期”阶段。费用使用当前全局费率。跨阶段月份归入重叠天数最多的阶段，同天数归较早阶段，每月只出现一次。

## 第一轮测试与修复

领域和真实 store 图测试覆盖命名/空白/复制、快照隔离、100% 精度守恒、月度差额、锁定/RBAC/预算归属、持久化、跨标签、失败操作不记成功日志和删除保留日志。

本轮发现并修复：共享动作初始化循环依赖；月度浮点精度；历史版本显示名被改写；部门身份/增删导致独立总额及精确比例丢失；配置快照等级被当前项目等级覆盖导致月度行消失。独立审查另外发现暂停/取消项目绕过正式校验，新增四类项目 × 三状态回归并关闭问题。

浏览器（Chrome，3051）以“示例tOS-独立跨年预算”验收：手填 V90.20 空白创建，里程碑模型直接可见；手填日期后显示排布对比；复制 V0.1 到 V90.21；比例超额提示及正式门禁；正式唯一/取消；锁定隐藏编辑、解锁恢复；月度 2.9→4.9 后显示目标 28.5、差额 +2.0；费用只读及年份筛选。修正月度后恢复平衡。费率 5→6 时，129.6 人月对应 777.60 万元，测试后恢复费率 5。
