- 共享主题为 Ant Design 默认、中号、小号表格统一设置 12px；共享 CSS 使用独立表头/内容字号变量。
- 表格内链接、状态标签、汇总和编辑控件统一字号；多级表头、横版行标题和甘特列头为 14px。
- 原生表格、权限矩阵、JIRA 配置表、分享页和需求计划甘特图接入同一规范。
- 更新《全系统 UI 规范》。保留行高、控件尺寸、页面正文、图标及业务交互。
