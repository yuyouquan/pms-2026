## 可复现方法

使用已构建的生产服务器，避免运行浏览器时重建同一 `.next`：

```sh
PMS_BASE_URL=http://127.0.0.1:3024 PMS_BROWSER_OUTPUT=output/playwright/figma-ui/final/release node screenshots/verify-figma-ui-browser.mjs
PMS_BASE_URL=http://127.0.0.1:3024 PMS_BROWSER_OUTPUT=output/playwright/figma-ui/final/release/transfer PMS_BROWSER_SCREENSHOTS=1 node screenshots/verify-transfer-browser.mjs
```

新验证器支持 `PMS_BASE_URL`、`PMS_BROWSER_OUTPUT`、`PMS_CHROME_EXECUTABLE` 和 `PMS_UI_SUITES`（逗号分隔套件名，供定向重跑；显式空值或未知名称会在浏览器启动前报错）。每个套件使用独立 BrowserContext，所有入口经可见导航/表单操作，不注入 Zustand、权限或业务数据；修改仅存在于该浏览器上下文。每个入口断言存在，不静默跳过。失败保存正文、截图及断言，并继续独立套件，以便一次发现更多问题。所有页面运行错误、console.error、HTTP>=400 均写入结果并使验证失败。

脚本默认输出 `output/playwright/figma-ui/final/`；本次最终验收通过上述参数保存在其 `release/` 子目录，包含逐页 PNG、`results.json`、`browser.log`，转维完整流程在 `release/transfer/` 和 `release/transfer.log`。这些是本地 QA 产物，不纳入源代码提交。较早证据保留用于核对修复过程。

## 当前实现边界

- 当前应用已无可见全局权限入口，源码也不再以 `globalPermission` 为导航状态。未恢复历史路由或注入状态；实际项目权限与普通用户权限已覆盖。
- HR“新建项目”当前跳转到“项目管理→项目配置”，随后“新项目”打开统一档案表单。旧HR独立创建弹窗不是当前入口。
- 两个独立模板URL当前复用 `LegacyPlanTemplateRoute`，验收共享配置中心的实际内容，而不是已移除的旧`.pms-config-center-switch`。
- 分享技术计划使用TDR节点，不沿用整机STR断言。分享仍是本地mock读取语义，没有后端持久化或跨浏览器同步声明。
- 宽资源/月度/计划表内部横向滚动是业务布局；验收禁止的是整个文档越过视口。

## 验证中修复的缺陷

1. 团队配置角色控件间距17px（8px上下padding加1px分隔线），与12px合同不符。实现方在 `50690b6` 修复；完整转维流程追加了实际几何断言。
2. 默认无专用class的资源新增版本弹窗主体0px内边距，字段贴边。实现方在 `8a6c6b3` 为默认非confirm弹窗恢复24px主体内边距；新验证器断言左右24px，并保留HR显式8px/12px竖向padding等布局。

3. 能力建设月度编辑沿用Ant默认top100px，而最大高度按viewport−48px计算，导致900px视口下页脚底部952px。`e951409` 将普通弹窗top改为24px、居中弹窗保持0，并为所有表单添加页脚/按钮视口边界断言及能力建设1280×800回归。
4. Ant相邻按钮margin8px叠加footer gap16px，实际间距24px。`e951409` 修正覆盖优先级，同时消除默认footer margin-top12px；改用实际按钮矩形间距断言。新断言在旧构建上按预期失败，在最终构建上通过。
