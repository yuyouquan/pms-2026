## 可复现方法

使用已构建的生产服务器，避免运行浏览器时重建同一 `.next`：

```sh
PMS_BASE_URL=http://127.0.0.1:3024 node screenshots/verify-figma-ui-browser.mjs
PMS_BASE_URL=http://127.0.0.1:3024 PMS_BROWSER_OUTPUT=output/playwright/figma-ui/final/transfer PMS_BROWSER_SCREENSHOTS=1 node screenshots/verify-transfer-browser.mjs
```

新验证器支持 `PMS_BASE_URL`、`PMS_BROWSER_OUTPUT`、`PMS_CHROME_EXECUTABLE` 和 `PMS_UI_SUITES`（逗号分隔套件名，供定向重跑）。每个套件使用独立 BrowserContext，所有入口经可见导航/表单操作，不注入 Zustand、权限或业务数据；修改仅存在于该浏览器上下文。每个入口断言存在，不静默跳过。失败保存正文、截图及断言，并继续独立套件，以便一次发现更多问题。所有页面运行错误、console.error、HTTP>=400 均写入结果并使验证失败。

默认输出 `output/playwright/figma-ui/final/`，包含逐页 PNG、`results.json`、`browser.log`；转维完整流程输出在 `transfer/` 和 `transfer.log`。这些是本地 QA 产物，不纳入源代码提交。

## 覆盖及度量

- 工作台计划/转维及项目组合管理。
- 项目管理列表、卡片、日历、配置，名称筛选和翻页后的实际数据变化；1440×900、1280×800、1920×1080；新增项目空值校验；编辑项目信息正常和1280×800低高度内部滚动。
- 整机、tOS、技术项目的基础信息、横版、竖版、甘特图、项目权限配置；修订计划无效日期的单元格高亮；非管理员可访问但不可编辑基础信息。
- 项目资源看板、年度预算/项目概算/项目预算/项目核算，创建版本正常/错误状态。
- HR四类人力项目列表、当前统一的新项目入口、版本列表、创建/编辑版本、月度列表和月度编辑；HR五类配置及新增弹层。
- tOS路标表单、版本演进、筛选；配置中心计划模板、转维材料、项目分类枚举、整机人力模型、非人力资源科目、费率行内数字输入及新增非人力资源科目。
- 技术计划分享的竖版/横版/甘特图；两个旧模板URL所指向的共享配置中心。
- 既有转维回归：选择九个团队角色成员、提交申请、独立材料及责任人、权限限制下的SPM资料录入、读回成功状态、关闭申请；新增团队字段12px间距断言。

几何记录每页最多150个数据单元格和100行，控件/标签/表头逐个测量。逐页断言共享Header50px、桌面左右32px、正文/表头/数据14px、标签24px/12px、可见普通控件32px、无文档横向溢出、测量占位行0px。项目列表的普通数据行严格40px；抽样数据行至少40px。表单断言item行尾12px、标签下4px、适用网格横向16px、footer64px/gap16px、弹层主体左右24px；错误文案末尾到下一字段12px；低高度表单主体滚动且footer完整留在视口内。键盘Tab可进入弹层。整机/tOS/技术的原生月度字段额外测量标签到控件4px及相邻控件横向16px。

表格长内容、合并单元格及控件容器允许自然增高。HR版本行60px的具体成因已查明：tOS版本中的`演示用户01`在窄修改人列折行，内容span高40px；普通内容20px、标签24px、操作32px。其他HR类别项目名也可折行。HR连续里程碑日期行`.pms-hr-version-row--milestones`采用8px列间距，属于合同允许的相关控件分组；独立字段网格仍为16px。结果保留每行高度及增高内容，不通过固定40px裁剪文本。

## 当前实现边界

- 当前应用已无可见全局权限入口，源码也不再以 `globalPermission` 为导航状态。未恢复历史路由或注入状态；实际项目权限与普通用户权限已覆盖。
- HR“新建项目”当前跳转到“项目管理→项目配置”，随后“新项目”打开统一档案表单。旧HR独立创建弹窗不是当前入口。
- 两个独立模板URL当前复用 `LegacyPlanTemplateRoute`，验收共享配置中心的实际内容，而不是已移除的旧`.pms-config-center-switch`。
- 分享技术计划使用TDR节点，不沿用整机STR断言。分享仍是本地mock读取语义，没有后端持久化或跨浏览器同步声明。
- 宽资源/月度/计划表内部横向滚动是业务布局；验收禁止的是整个文档越过视口。

## 验证中修复的缺陷

1. 团队配置角色控件间距17px（8px上下padding加1px分隔线），与12px合同不符。实现方在 `50690b6` 修复；完整转维流程追加了实际几何断言。
2. 默认无专用class的资源新增版本弹窗主体0px内边距，字段贴边。实现方在 `8a6c6b3` 为默认非confirm弹窗恢复24px主体内边距；新验证器断言左右24px，并保留HR显式8px/12px竖向padding等布局。

源代码构建、静态验证及浏览器最终结果由下方最终记录补充。历史域验证器兼容性问题记录于 `.superpowers/sdd/2026-09-20-figma-system-ui/baseline-findings.md`：HR旧审计假设与现行独立版本语义冲突，项目管理旧审计对含undefined的结构化快照与JSON读回做严格深比较；本次没有放宽业务约束。
