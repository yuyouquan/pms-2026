# 所有项目空间查看权限验收

## 范围

- 权限中心：项目管理 → 所有项目空间 → 查看。仅新增查看，普通角色默认不授权。
- 角色的人员和部门授权沿用现有规则；系统超级管理员仍拥有全部权限。
- 全局查看可补足 IPM 同步角色未勾选的查看权限；项目角色及联合计划已有的操作权限独立保留。
- 顶部“所有项目空间”提供名称、编码、类型、属性搜索；空间内项目切换及项目列表、配置、通知、分享计划入口统一识别授权。
- 覆盖当前及后续项目；外层项目视图的数据筛选、列设置、关于我的成员范围保持独立。
- 查看不新增编辑、导入、导出、分享、发布、转维操作或角色管理权限。取消授权不修改项目内的角色副本。
