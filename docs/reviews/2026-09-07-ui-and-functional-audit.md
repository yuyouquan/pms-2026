## 已修复的问题

1. **项目权限与会话隔离**：进入项目后切换非成员仍能看到内容；旧用户的编辑弹窗可能残留。项目入口实时校验角色，切换用户/项目关闭旧局部状态，内容区及编辑、转维、比较、导出、分享操作按权限限制。
2. **离开确认**：确认后没有真正执行导航。修正回调保存方式，并覆盖基础信息未保存状态。
3. **旧缓存兼容**：项目状态为空时读取报错；升级缓存时可能在已有用户草稿旁加入第二个演示修订版。保留原数据，修正容错和迁移选择。
4. **转维状态闭环**：新申请未生成独立材料，录入/审核与阶段状态脱节，SQA 确认只提示成功，部分关闭入口无操作。统一工作流计算、参与人/阶段校验、模板材料初始化及关闭流程。
5. **转维待办路由**：委托申请错误地归给申请人，同名项目可能跳错。录入归属在研 SPM，优先匹配准确项目 ID，仅旧 `proj_数字` 记录允许名称兼容。
6. **旧模板路由**：旧地址使用独立示例数据和编辑逻辑。现在复用当前配置中心的数据、权限和离开确认。
7. **计划分享数据**：普通分享链接读取固定 V3 与演示任务，各市场计划相同。现在读取对应市场/tOS 类型的最新已发布快照；未发布或不支持的链接显示明确空状态，不再伪造历史日期。
8. **样式遗漏**：路标局部 30px 控件、遗留正文与小标题字号、独立甘特图 35px 行高、弹窗重复内边距统一到公共规范；转维角色标签修正浅底白字，默认弹窗、分页和日期控件统一中文。
