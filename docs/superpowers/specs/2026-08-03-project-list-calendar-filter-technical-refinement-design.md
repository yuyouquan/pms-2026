# 项目列表三视图、技术项目信息与计划工作台对齐设计

日期：2026-08-03  
状态：已确认，待实施计划

## 1. 目标与范围

本次迭代统一项目列表的列表、卡片、日历三种视图，使它们共享项目分类、二级分类、项目状态、快捷筛选、高级筛选和“关于我的”结果；同时修复整机列表固定列错位，完善技术项目新建、编辑和项目空间的信息结构，并让技术项目计划完整复用整机产品项目的计划工作台展示与操作形式。

本次不改变项目空间左侧导航、计划版本模型、权限授予规则和配置中心模板数据模型。

## 2. 总体方案

采用现有项目列表容器上的渐进式扩展：

- `ProjectListContainer` 统一维护视图模式、分类筛选、聚合状态筛选、“关于我的”和当前过滤结果。
- `ProjectSummaryTable` 继续负责列表视图，并修复固定列宽度契约。
- 新增项目列表日历组件，复用项目总汇看板的月份导航、七列日历、节点事件和视觉样式。
- `ProjectCard` 和技术子项目卡片消费与列表视图相同的过滤结果。
- `SortableColumnSettings` 增加共享搜索，因此所有调用方自动获得列搜索能力。
- 从整机计划中抽取共享任务表格和计划工作台契约；整机、tOS、技术 TDT 和技术子项目通过数据适配器接入同一套展示与交互。

三种视图不各自保存筛选条件，避免切换视图后结果不一致。

## 3. 项目列表筛选与统计

### 3.1 视图模式

视图顺序固定为：

1. 列表视图
2. 卡片视图
3. 日历视图

视图切换使用浅色胶囊容器，选中项为白色浮层。新增项目按钮使用紧凑尺寸，并保持在项目分类行右侧。

### 3.2 分类行

- `项目二级分类` 展示名改为 `二级分类`。
- `状态` 展示名改为 `项目状态`。
- 整机产品项目继续展示现有二级分类和详细项目状态。
- tOS 版本项目展示 `二级分类：全部`，并展示聚合项目状态。
- 技术项目以 `项目类型：TDT项目/子项目` 作为第二行，并展示聚合项目状态。
- 能力建设项目继续显示未配置内容，但筛选面板保持统一高度。

### 3.3 tOS 与技术项目聚合状态

聚合状态固定为 `全部 / 进行中 / 已完成`：

- 进行中：`待立项、规划中、在研、进行中、待验`
- 已完成：`已完成、上市、转维、EOS、已迁移`
- `暂停、已取消` 只在“全部”中出现，不归入进行中或已完成。

状态匹配必须兼容 IPM 原始状态与 PMS 展示状态。

### 3.4 关于我的

快捷筛选末尾增加 `关于我的` Checkbox，默认选中。

项目命中规则：`permission.rolesByProject[projectId]` 中任意角色的 `members` 包含当前登录用户。技术子项目使用所属 TDT 项目权限。

- 选中：在用户原有可见范围内，仅展示角色成员包含当前用户的项目。
- 取消：恢复用户原有可见范围。
- 管理组仍保留全局查看能力，但默认选中时同样只看角色中包含自己的项目。

### 3.5 分类数字

- 所有分类数字先响应“关于我的”。
- 当前分类数字继续响应二级分类、项目状态、项目类型、快捷筛选和高级筛选。
- 切换项目分类时清空上一分类的专属筛选条件并重新计算。
- 卡片分页总数、列表行数、日历事件来源和分类数字必须来自同一过滤结果。

## 4. 快捷筛选与列设置

### 4.1 快捷筛选

- 输入框和 Select 使用紧凑高度、紧凑宽度和统一圆角。
- 多选 Select 强制单行，最多展示一个标签，其余显示数量，禁止标签换行撑高工具栏。
- 筛选、列设置按钮与输入控件同高。
- 三种视图切换后保留当前筛选条件。

### 4.2 列设置搜索

`SortableColumnSettings` 顶部增加搜索框：

- 按列标题和可访问名称进行不区分大小写的包含匹配。
- 搜索只改变面板中可见条目，不改变列的顺序、显隐和固定属性。
- 清空搜索恢复完整列列表。
- 打开新的列设置面板时搜索词重置。
- 搜索无结果时展示明确空状态。

## 5. 列表视图固定列

- 整机 `产品系列` 和 `项目名称` 使用同一个列定义宽度生成表头、`colgroup` 和固定内容层。
- 产品系列保持单行；超长时省略，悬停显示完整名称。
- 分组单元格不能通过内部最小宽度扩大固定列。
- Ant Design 测量行保持零高度、零内边距。
- 横向滚动前后，固定列表头和首行内容的 `x/width` 必须一致。

## 6. 日历视图

日历复用项目总汇看板交互：

- 月份标题、上月、今天、下月。
- 周日至周六七列布局，显示当前月前后补位日期。
- 事件来源为当前过滤结果中的计划模板节点日期。
- 事件标题为 `节点名称 + 项目名称`，颜色沿用项目分类主题色。
- 单日最多直接显示四条，更多显示数量。
- 点击事件进入对应项目空间；技术子项目事件进入所属 TDT 项目并定位子项目 Tab。
- 没有有效日期的项目不生成事件，但仍保留在列表和卡片视图中。

## 7. 技术项目新建与编辑

- 技术信息标题旁删除 `IPM 同步` 标签。
- 前置项目对所有技术项目始终显示，非必填。
- 删除“仅技术项目前置工作显示”和切换 IPM 项目时自动清空前置项目的逻辑。
- 项目年份为必填四位年份。
- 新建和编辑使用同一字段规则。
- 项目责任人继续取技术项目负责人，不新增单独责任人字段。

## 8. 技术项目空间

- 核心信息移除前置项目，保留项目名称、项目分类、技术赛道、TMG及技术领域、子领域、项目阶段、项目年份和项目价值。
- TDT Tab：组合卡片中只显示计划信息。
- 子项目 Tab：同一外层组合卡片内依次显示计划信息和子项目基础信息，两者随 Tab 一起切换。
- 团队信息和交付物信息继续作为组合卡片外的独立折叠模块。
- 子项目信息配置入口、只读状态和权限判断保持不变。

## 9. 技术项目计划工作台完全对齐

### 9.1 共享边界

采用“共享工作台 + 类型适配器”，不复制整机计划表格代码，也不把技术计划数据迁移到通用计划 Store：

- 共享层负责工具栏布局、版本状态展示、任务表格、列宽与固定列、层级序号、编辑态、只读态、空状态和三种视图切换。
- 整机与 tOS 继续使用现有计划 Store；技术项目继续使用独立的 `technicalPlan` Store、TDT/子项目作用域和独立版本快照。
- 适配器提供任务读取、更新、增删、排序、发布校验、权限判断和版本操作，UI 不直接判断项目类型。
- 技术项目保留 TDT 最多两级任务、子项目仅一级任务的领域限制；共享层根据适配器返回的最大深度决定是否显示“添加子任务”。

### 9.2 工具栏一致性

技术计划使用与整机计划相同的工具栏结构、尺寸、间距、图标顺序和状态：

- 版本选择器使用 `版本号（已发布/修订中）` 格式。
- 已发布版本显示“创建修订”；修订中版本显示自动保存、计划克隆、发布和取消修订。
- 创建修订继续支持正式和非正式版本，但入口外观和整机一致。
- 右侧依次提供筛选、导出、列设置、全部展开、全部收起、版本对比、导入、分享以及列表/甘特/横版切换；不适用或无权限的操作保留位置并展示明确禁用原因。
- TDT/子项目 Tab 位于共享工具栏之前，仍由技术项目作用域控制。

### 9.3 列表视图一致性

技术计划列表视图与整机计划使用同一列定义、列宽和渲染器，默认顺序固定为：

`序号 / 任务名称 / 责任人 / 前置任务 / 计划开始 / 计划完成 / 预估工期 / 实际开始 / 实际完成 / 实际工期 / 状态 / 进度 / 操作`

- `序号` 固定在左侧；草稿态的 `操作` 固定在右侧，发布态不展示空操作列。
- 序号列统一承担拖拽手柄、展开收起、添加子任务和层级编号；任务名称列只展示名称和层级缩进。
- 删除技术计划现有的“阶段”标签式表达，一级/二级关系以 `1 / 1.1 / 1.2` 和树形缩进表达。
- 草稿态统一使用黄色编辑提示、黄色行底色、紧凑输入控件、日期冲突单元格提示和底部全宽“添加新活动”。
- 发布态统一使用负责人头像、前置任务标签、状态标签和进度条；最新已发布版本的实际开始/完成日期遵循整机计划现有的维护权限与交互。
- 拖拽只允许同级任务，完成后统一重排并重新生成层级序号；筛选激活时停用拖拽，避免隐藏行造成错误排序。

### 9.4 列设置与兼容迁移

- 共享列设置定义包含不可隐藏的 `序号` 和 `任务名称`，其他业务列可配置。
- 技术计划已有本地持久化配置在迁移时补入 `序号`，保留用户原有列顺序与显隐选择，不重置全部偏好。
- 历史技术任务 ID 在载入时保持稳定；仅在新增或同级拖拽后按现有规则重新编号。
- 甘特图和横版视图继续读取同一过滤结果和版本快照，切换视图不改变计划数据。

## 10. 数据流与兼容

过滤顺序统一为：

`原始项目 → 权限可见范围 → 关于我的 → 项目分类 → 二级分类/项目类型 → 聚合状态 → 快捷筛选/高级筛选 → 三视图数据`

现有 Zustand 持久化中的 `card/list` 值继续兼容；新增 `calendar` 值。读取未知旧值时回退到 `list`。

既有项目没有项目年份时仍可正常展示；只有新建和编辑提交时执行必填校验。

技术计划工作台数据流为：

`技术计划作用域 → 可见版本 → 当前版本 → 权限/修订态 → 筛选与折叠 → 共享任务表格/甘特/横版`

共享展示层只接收适配后的任务和操作回调，技术计划发布、取消、导入、分享及版本权限仍由技术计划领域层负责。

## 11. 错误与空状态

- 日历当月无节点时显示日历空网格，不隐藏月份导航。
- 列搜索无结果显示“未找到匹配列”。
- “关于我的”无结果时，三种视图使用一致空状态，并允许用户取消勾选。
- 技术项目年份缺失时表单在字段下显示必填提示并阻止提交。
- 技术计划日期冲突时自动展开并定位第一个异常任务，阻止发布。
- 技术计划没有版本时展示“暂无计划版本，请创建修订”，工具栏保持稳定不跳高。
- 无编辑、发布、导入或分享权限时按钮保持一致位置并通过 Tooltip 说明原因。

## 12. 测试与发布

自动化契约：

- 三种视图顺序和共享过滤结果。
- tOS 二级分类、tOS/技术聚合状态及别名匹配。
- “关于我的”按项目权限角色成员匹配，技术子项目回溯所属 TDT。
- 分类数字随筛选更新。
- 列设置搜索不改变列配置。
- 前置项目始终显示且非必填，项目年份必填，核心信息不显示前置项目。
- 子项目计划和基础信息位于同一组合容器。
- 产品系列不换行，固定列表头与内容宽度一致。
- 技术 TDT 与技术子项目均使用共享计划工作台，技术模块不再维护独立任务表格渲染器。
- 技术计划草稿态与整机草稿态具有相同列顺序、固定列、层级序号、拖拽、子任务、新增活动、校验和操作列规则。
- 技术计划发布态与整机发布态具有相同负责人、前置任务、状态、进度和实际日期交互。
- 技术计划工具栏在已发布、正式修订、非正式修订、无权限和无版本五种状态下与整机计划结构一致。
- TDT 两级限制和子项目一级限制在共享表格中仍然生效。
- 技术计划旧列配置迁移后保留原有选择并自动补入不可隐藏序号列。

浏览器验收覆盖整机、tOS、技术 TDT、技术子项目，逐项检查列表、卡片、日历、筛选联动、列搜索、新建/编辑和项目空间；计划页面需对照整机与技术项目的草稿态、发布态截图逐列检查表头、行高、固定列、按钮顺序和操作结果。

发布门禁为契约脚本、`npx tsc --noEmit`、`npm run build` 和浏览器检查。全部通过后提交功能分支，合并推送 `dev`，再合并推送实际主干 `master`。
