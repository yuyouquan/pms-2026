# 项目路标快速迭代设计

## 目标

在现有项目路标模块上完成项目名、tOS 版本、版本维护、筛选、版本演进和 STR5 预估能力升级。继续使用 `projectStore` 作为正常项目数据源、`roadmapStore` 作为待规划项目和路标配置数据源，不建立第二套路标状态。

## 1. 项目名显示

- 路标中的项目名以 `projectCode` 为唯一来源，不使用正常项目的完整 `name`。
- 新品显示 `projectCode`，例如 `CN6`。
- 老品显示 `projectCode(Android 版本)`，例如 `CN6(Android 16)`。
- 表格视图、版本演进卡片、修改记录、冲突抽屉和审计快照统一使用同一格式化函数。
- 冲突键仍为 `projectCode + Android 版本 + 产品类型`，本次只修正显示，不改变冲突判定。

## 2. tOS 三位版本和显示规则

- `TosVersionConfig` 增加 `patch`，完整版本按 `major.minor.patch` 保存、校验、排序和判重。
- tOS 15 及以前在所有视图显示三位，例如 `tOS 15.2.1`。
- tOS 16 及以后在业务视图显示两位，例如完整版本 `17.2.0` 显示为 `tOS 17.2`，悬停可查看完整三位版本。
- tOS 版本维护始终显示和编辑完整三位版本。
- 新增 tOS 16 及以后版本时，同一 `major.minor` 不允许重复。
- 历史数据中同一 `major.minor` 的多个完整版本允许保留，迁移不得删除或合并。
- 旧的两位版本自动补 `patch = 0`。

## 3. tOS 版本卡片维护

- 删除弹窗顶部独立的新增/编辑表单。
- 点击“新增版本”后，在列表顶部插入一张编辑态卡片并聚焦版本输入框。
- 点击普通卡片“编辑”后，该卡片原地进入编辑态。
- 同一时间只允许一张卡片处于编辑态；有未保存修改时切换编辑对象需确认。
- 编辑态字段依次为：完整 tOS 版本、项目周期日期范围、版本目标多行文本。
- 编辑态右侧显示“取消、保存”。
- 普通态右侧只显示“编辑、删除”；被项目引用时删除保持禁用并解释原因。
- 项目周期允许为空，保存为开始日期和结束日期。
- 版本演进列头目标卡片显示项目周期；未设置时不占位。

## 4. 目标折叠和视图切换

- 表格视图和版本演进视图进入时，版本目标默认收起。
- 用户可按已有按钮展开。
- 从表格视图切换到版本演进视图时，清除所有 tOS 版本筛选值，避免单版本状态误带入多版本对比。

## 5. 多选筛选

- `enum`、`ram` 和 `tos-version` 类型筛选值改为多选。
- 同一条件内多个值按 OR 匹配；不同条件之间仍按 AND 匹配。
- 文本和日期条件保持单值。
- 快捷品牌、产品类型筛选与抽屉仍共享同一筛选状态。
- 旧的单值筛选在迁移时转换为单元素数组。

## 6. 版本演进 tOS 对比

- 版本演进视图读取多选 tOS 条件。
- 存在 tOS 筛选时，仅渲染命中的版本纵列；未筛选时渲染全部版本。
- 纵列仍按完整语义版本排序。
- 历史版本完整号不同但业务显示名相同的情况，通过悬停完整号和稳定版本 ID 区分。

## 7. STR5 预估

- 待规划项目新增布尔字段 `str5Estimated`，默认 `false`。
- 创建和编辑待规划项目时，在 STR5 日期选择器后显示“预估”复选框。
- 勾选后，表格日期和版本演进项目卡片显示“预估”标签。
- 正常项目若没有该字段按 `false` 处理。
- 本轮不把预估状态加入修改记录字段白名单。

## 数据迁移

- 路标持久化版本升级。
- 两位 tOS 版本补 `.0`；历史三位版本原样保留。
- 旧单值枚举/tOS 筛选转换为数组。
- 缺失的项目周期和 `str5Estimated` 使用空值和 `false`。
- 已删除的 Mock、用户创建项目和引用保护状态不得被迁移重新生成。

## 错误处理

- 三位版本格式错误在卡片字段下提示。
- 新 tOS 16+ 与已有 `major.minor` 冲突时阻止保存。
- 项目周期开始晚于结束时阻止保存。
- 筛选引用已删除版本时自动移除无效值。
- 保存失败保留当前编辑态和用户输入。

## 快速验证

- 路标契约脚本覆盖三位版本迁移、显示规则、多选筛选和 STR5 预估。
- 运行 `npx tsc --noEmit`。
- 浏览器冒烟验证：
  - `CN6_H902` 在路标相关界面显示为 `CN6`；
  - 新增/编辑 tOS 卡片交互；
  - 周期显示和默认目标收起；
  - 多选 tOS 后演进纵列数量变化；
  - STR5 预估标签。
