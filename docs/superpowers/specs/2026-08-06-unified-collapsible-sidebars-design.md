# 配置中心与项目空间统一可收起侧栏设计

## 1. 背景与目标

当前配置中心三个页签的页面结构不一致：计划模板配置已使用左右分栏，转维材料模板配置先展示入口卡片再进入配置表格，枚举值配置虽然使用左右分栏，但左右卡片高度不一致。项目空间左侧导航固定占用 200px，无法收起。

本次调整目标：

1. 计划模板配置、转维材料模板配置、枚举值配置统一为“左侧分类导航 + 右侧配置内容”的双栏工作区。
2. 配置中心左、右模块填满同一可用高度，消除高低不一致和页签切换时的布局跳动。
3. 配置中心左侧导航支持展开和收起，控制按钮固定在侧栏内部右下角。
4. 项目空间左侧菜单支持相同的展开和收起交互。
5. 保持既有数据、权限、编辑保护和业务操作不变。

## 2. 设计原则

- **统一**：相同层级使用相同的宽度、间距、卡片边界、选中态、收起按钮和动效节奏。
- **稳定**：页签切换和侧栏收起时不产生垂直跳动；主内容自动补齐空间。
- **可识别**：收起后仍显示分类或菜单图标、当前选中态和 Tooltip，不完全隐藏导航入口。
- **可访问**：按钮支持键盘操作，具有明确的辅助名称、展开状态和焦点样式。
- **少改业务**：只调整信息架构和布局，不改变模板、枚举值、权限或项目空间模块的数据契约。

## 3. 总体信息架构

### 3.1 配置中心统一外壳

配置中心顶部保留三个页签：

1. 计划模板配置
2. 转维材料模板配置
3. 枚举值配置

三个页签下方统一使用 `ConfigWorkspaceShell` 结构：

- 左侧：`ConfigWorkspaceSidebar`
- 右侧：`ConfigWorkspaceContent`
- 展开宽度：约 250px，可在 224–280px 范围内适配。
- 收起宽度：64px。
- 分栏间距：16px。
- 工作区最小高度：配置内容视口的剩余可用高度；左右卡片使用同一高度并各自管理内部滚动。
- 收起按钮：固定在左侧卡片内部右下角，菜单滚动时按钮位置不变。

### 3.2 三个页签的左侧导航映射

| 页签 | 左侧一级项 | 左侧二级项或说明 | 右侧内容 |
| --- | --- | --- | --- |
| 计划模板配置 | 项目分类 | 整机产品项目、tOS版本项目、技术项目、能力建设项目 | 当前项目分类的模板、层级与版本配置 |
| 转维材料模板配置 | 配置类型 | 转维材料、评审要素 | 当前类型的模板表格、搜索、版本、导入导出、版本对比 |
| 枚举值配置 | 枚举分类 | 通用下包含 tOS版本（2位）、tOS版本（3位）；人力资源管道按实际枚举类型展示 | 当前枚举类型的枚举值表格与新增、编辑、删除 |

转维材料模板配置不再使用单独的入口卡片首页。进入页签时默认选中“转维材料”，点击左侧“评审要素”后直接替换右侧内容。原有搜索、版本选择、导入、导出和版本对比继续保留。

## 4. 配置中心侧栏交互

### 4.1 展开态

- 显示侧栏标题、分类名称、数量或辅助说明和分类图标。
- 当前分类使用浅紫背景、主色文字和左侧强调线。
- 右下角显示“收起侧栏”按钮，图标方向指向左侧。
- 左侧菜单内容超过可用高度时，仅菜单区滚动；标题和右下角按钮保持可见。

### 4.2 收起态

- 侧栏宽度收缩到 64px。
- 隐藏长文本和数量文字，仅显示分类图标。
- 每个图标项提供 Tooltip，内容为完整分类名称。
- 当前分类保留选中背景和强调线。
- 右下角显示“展开侧栏”按钮，图标方向指向右侧。
- 点击分类图标仍可切换右侧配置内容。

### 4.3 状态范围

- 三个配置中心页签共享一个 `configSidebarCollapsed` 状态，切换页签时保持侧栏宽度，避免跳动。
- 项目空间使用独立的 `projectSpaceSidebarCollapsed` 状态，不与配置中心互相影响。
- 本期不要求跨浏览器刷新持久化；刷新后默认展开。

### 4.4 辅助功能

- 收起按钮使用原生按钮语义，设置 `aria-label="收起侧栏"` 或 `aria-label="展开侧栏"`。
- 设置 `aria-expanded` 表示当前状态。
- 分类图标项在收起态保留可读的辅助名称。
- `Tab` 顺序遵循页面视觉顺序：页签 → 左侧分类 → 收起按钮 → 右侧操作区。
- 键盘 `Enter` 和 `Space` 均可触发按钮和分类选择。
- 焦点态使用清晰的主色外圈，不移除浏览器焦点提示。

## 5. 项目空间侧栏交互

### 5.1 展开态

- 保持现有 200px 左侧导航及所有菜单项：基础信息、概况、需求、计划、资源、任务、风险、缺陷、团队、项目文档、权限配置。
- 收起按钮固定在侧栏内部右下角。
- 菜单区独立滚动，按钮始终可见。

### 5.2 收起态

- 侧栏宽度收缩到 64px，仅显示既有菜单图标。
- 菜单项 Tooltip 显示完整模块名称。
- 当前模块保留既有选中背景和左侧主色标记。
- 右侧项目内容区域自动占用释放出的空间。
- 收起/展开本身不触发页面导航，不重置转维视图，不清理当前项目和滚动位置。

### 5.3 导航与编辑保护

- 点击菜单仍通过 `navigateWithEditGuard` 执行，现有修订中编辑保护保持不变。
- 收起/展开属于布局操作，不经过编辑保护，也不会造成未保存内容丢失。
- 切换项目空间菜单时继续执行既有 `transfer.setTransferView(null)` 逻辑。

## 6. 组件与状态设计

### 6.1 共享组件

新增或抽取以下轻量组件：

- `CollapsibleSidebarShell`：负责统一展开/收起宽度、等高布局、菜单滚动区和右下角按钮。
- `ConfigWorkspaceShell`：负责配置中心左右双栏结构和右侧内容容器。

组件只接收展示状态和回调，不持有业务数据：

```ts
interface CollapsibleSidebarShellProps {
  collapsed: boolean
  onCollapsedChange: (collapsed: boolean) => void
  title: React.ReactNode
  children: React.ReactNode
  expandedWidth?: number
  collapsedWidth?: number
  ariaLabel: string
}
```

### 6.2 Zustand 状态

在 UI Store 中拆分两个布局状态：

- `configSidebarCollapsed`
- `projectSpaceSidebarCollapsed`

现有通用 `sidebarCollapsed` 迁移为配置中心状态或保留兼容别名，避免计划模板现有调用失效。枚举、转维和计划模板读取同一个配置中心状态；项目空间读取独立状态。

### 6.3 数据流

1. 用户点击右下角按钮。
2. 对应 Zustand 布局状态更新。
3. 侧栏组件切换宽度、标签可见性、Tooltip 和 `aria-expanded`。
4. CSS Grid/Flex 重新分配主内容宽度。
5. 业务 Store、当前选择、表格数据和编辑草稿不发生变化。

## 7. 样式规则

- 左右卡片使用现有 PMS 紫色玻璃拟态体系，不引入新的独立色板。
- 卡片圆角统一为 12px，边框和阴影使用当前枚举配置的轻量层级。
- 分类行最小点击高度 40px；右下角按钮可视尺寸 36–40px，点击区域至少 44px。
- 标题、正文和辅助文字继续使用现有 14/13/11px 层级。
- 切换动效控制在约 180ms，只用于侧栏宽度、内容透明度和选中态。
- `prefers-reduced-motion: reduce` 时关闭侧栏过渡动画。
- 不使用 Emoji，继续使用 Ant Design 图标。

## 8. 响应式规则

- 桌面宽度大于 1024px：使用完整双栏布局和可收起窄栏。
- 768–1024px：默认允许收起为 64px，右侧内容保持最小可读宽度。
- 小于 768px：配置中心上下堆叠；左侧分类改为顶部横向/换行分类区，右下角收起按钮隐藏，避免形成过窄竖栏。项目空间保持现有桌面优先约束，本次不引入移动端抽屉重构。
- 任意宽度下不得让右下角按钮覆盖最后一个菜单项，菜单滚动区需预留底部空间。

## 9. 异常与边界处理

- 枚举分类无枚举类型时，右侧继续显示当前空状态；侧栏仍可正常收起和展开。
- 转维模板列表为空时，右侧显示表格空状态，不恢复入口卡片首页。
- 分类名称过长时展开态单行省略并提供 Tooltip；收起态只显示图标。
- 页面高度较低时，侧栏菜单滚动而不是让收起按钮超出视口。
- 如果当前项目空间模块没有对应内容，继续使用既有“模块开发中”空状态。

## 10. 不在本次范围

- 不新增或修改枚举值业务类型。
- 不修改计划模板、转维模板的版本规则和表格字段。
- 不修改项目空间菜单权限或业务模块。
- 不实现侧栏状态的服务端或本地持久化。
- 不重构配置中心顶部页签导航。

## 11. 验收标准

### 11.1 配置中心

1. 三个页签均使用相同的双栏外壳。
2. 左、右卡片顶部和底部对齐，并填满可用高度。
3. 页签切换时侧栏宽度和收起状态保持不变。
4. 转维材料和评审要素可通过左侧直接切换，原操作功能可用。
5. 右下角按钮在长菜单滚动和低窗口高度下仍可操作。
6. 收起后所有分类可通过图标和 Tooltip 识别并切换。

### 11.2 项目空间

1. 左侧菜单可在 200px 和 64px 间切换。
2. 收起后全部菜单图标、选中态和 Tooltip 正常。
3. 右侧内容自动扩展，无横向遮挡和内容跳失。
4. 收起/展开不改变当前模块、项目、转维子视图或编辑草稿。
5. 菜单点击继续遵循编辑保护。

### 11.3 质量与无障碍

1. 按钮可通过键盘操作并正确暴露 `aria-expanded`。
2. 焦点样式清晰，图标按钮具有可读名称。
3. 减少动态效果设置下不播放侧栏过渡。
4. `npx tsc --noEmit` 通过。
5. `npm run build` 通过。
6. 浏览器手动覆盖：三个配置页签的展开/收起与切换、转维类型切换、枚举类型切换、项目空间全部菜单导航、编辑保护、低高度与常用桌面宽度。

## 12. 实施顺序建议

1. 先拆分 UI Store 的两个侧栏状态并增加共享侧栏组件。
2. 将计划模板配置接入统一外壳，作为样式基准。
3. 将转维材料模板从首页卡片入口迁移为左侧类型导航。
4. 将枚举配置接入统一外壳并修复左右等高。
5. 将项目空间菜单接入共享可收起侧栏。
6. 补充源代码契约验证、类型检查、构建和浏览器验收。
