# 配置中心视口高度与枚举树设计

## 目标

- 配置中心内容始终限制在浏览器可用高度内，不再把页面撑出一屏。
- 左右区域保持等高，内容过多时在区域内部滚动。
- 枚举分类改为适合大量类型扩展的紧凑树形导航。

## 交互与视觉

- 桌面端配置工作区高度为 `100dvh` 扣除主 Header、配置页签与页面间距后的剩余空间，同时保留 420px 最小可用高度。
- 左侧分类和右侧内容均占满工作区，滚动只发生在各自内容区；侧栏右下角展开/收起按钮保持固定。
- 枚举树一级节点为“通用”“人力资源管道”，二级叶子为具体枚举类型。
- 节点使用 32px 左右的紧凑行高、树枝引导线、文字和数量；去除卡片边框、大图标及双行说明。
- 选中分类和类型均提供明确的浅紫背景；选中类型增加左侧强调线。
- 侧栏收起时保留分类图标入口及 Tooltip，避免丢失可操作性。
- 小屏沿用单列布局并恢复自然高度，避免嵌套滚动。

## 验收

- 1440x900 和常见桌面视口下，配置中心外层不超过可见区域。
- 左右栏高度一致；内容增长时只在内部滚动。
- 至少 20 个枚举类型时，树仍可快速扫描并可滚动访问。
- 键盘焦点、ARIA 标签、选中状态和侧栏展开收起功能保持可用。

## 同批工作台优化

- 搜索、项目、任务分类、生成时间、清空五类控件统一为 32px 高度和一致圆角。
- 桌面端按 280/200/220/300/88px 的视觉优先级组成紧凑控件组，不再平均拉伸至整行。
- 可用宽度不足时按控件整体换行，字段内部仍保持单行和可读性。
- 表格将“任务”改为“任务来源”，只展示计划待办或转维待办；新增“任务节点”列，独立展示具体节点及上下文。
