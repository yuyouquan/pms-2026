# 项目路标“全部 tOS”与卡片单行设计

## 目标

表单视图的 tOS 选择器增加“全部”选项，并在首次进入时默认选中；版本演进视图统一品牌色、锁定卡片标题字段并优化标签展示。

## 交互设计

### 表单视图 tOS 选择

- 下拉第一项固定为“全部”，其后按语义版本降序展示已维护的 tOS 版本。
- 初始状态和没有 tOS 筛选条件时选择“全部”。
- “全部”展示经过品牌、产品类型及其他筛选后的全部 tOS 项目，不显示单一版本目标卡片。
- 选择具体版本时，筛选抽屉同步为 `tOS版本 = 所选版本`。
- 筛选抽屉应用具体 tOS 等于条件时，下拉同步到对应版本；删除 tOS 条件后下拉回到“全部”。
- 切换到版本演进视图时不新增 tOS 条件，仍按当前筛选结果铺开版本列。

## 版本演进品牌与卡片规则

### 品牌色

- TECNO 品牌名称和圆点使用蓝色。
- Infinix 品牌名称和圆点使用绿色。
- itel 品牌名称和圆点使用红色。

### 卡片标题与单行规则

- 卡片标题固定为 `产品系列（项目名）`，使用中文全角括号。
- “产品系列”和“项目名”在版本演进列设置中固定为已勾选且禁用，用户不能移除。
- 标题字段仅在卡片头部展示，详情区不重复展示产品系列和项目名。
- 卡片标题与“待规划”标签在同一水平行。
- “待规划”标签禁止收缩和换行。
- 可用宽度不足时标题使用单行省略号，不把标签推到下一行。
- 正常项目标题同样保持单行省略。

### 版本类型 Tag

- 版本类型不再显示为普通文本，改为彩色 Tag。
- Full 使用蓝色 Tag，Slim 使用金色 Tag，Go 使用青色 Tag。
- 空值仍显示 `—`，不渲染空 Tag。

## 状态与兼容

- `selectedTosVersionId = null` 表示“全部”。
- 旧持久化状态中的合法具体版本继续保留；缺失、无效或已删除的版本回退到“全部”。
- “全部”对应筛选条件中不存在 `firstSaleTosVersionId` 条件，避免双重状态源。

## 验证

- 默认进入表单视图时下拉显示“全部”，表格可同时出现多个 tOS 版本。
- “全部 → 具体版本 → 抽屉删除 tOS 条件”双向联动正确。
- TECNO、Infinix、itel 的名称和圆点分别使用蓝、绿、红色。
- 产品系列和项目名在版本演进列设置中锁定，卡片标题固定为 `产品系列（项目名）`。
- 标题很长时出现省略号，“待规划”标签仍保持同一行。
- Full、Slim、Go 分别显示蓝、金、青色 Tag。
- 类型检查和项目路标聚焦校验通过。
