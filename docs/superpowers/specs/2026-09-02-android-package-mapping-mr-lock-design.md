# 安卓版本、组包方式映射与联合计划锁定设计

日期：2026-09-02

## 1. 目标与范围

本次调整覆盖五个相互关联的能力：

1. 在配置中心枚举值配置中新增“安卓版本”和“组包方式”。
2. 联合项目空间“tOS&整机1+N项目计划”展示整机项目芯片编码，并根据项目安卓版本和芯片型号自动映射组包方式。
3. 联合计划支持版本项目经理和超级管理员批量锁定、解锁整机项目行，并根据锁定状态收紧编辑权限。
4. 项目空间一级计划横版视图显示版本发布日期，基础信息横版视图在最新发布版本下补充只读修订版本。
5. 项目列表移除已停用的项目状态，并把全部 Mock 项目刷新为各项目类型当前有效的状态枚举。

不调整一级计划、三级计划日期校验、EOS 隐藏、tOS 基准行只读及现有筛选规则。

## 2. 枚举配置设计

### 2.1 安卓版本

- 配置名称：`安卓版本`
- 类型：单值枚举
- 表格列：`序号 / 安卓版本 / 操作`
- 编辑控件：文本输入框
- 校验：去除首尾空格后不能为空；同名值不可重复。
- 初始数据：不新增未经确认的业务枚举值，保留管理员自行维护能力。

### 2.2 组包方式

- 配置名称：`组包方式`
- 类型：映射枚举
- 表格列：`序号 / 安卓版本 / 芯片型号 / 组包方式 / 操作`
- 安卓版本：从“安卓版本”配置中单选，支持搜索。
- 芯片型号：从“芯片编码/芯片型号/芯片厂商”映射配置中的芯片型号去重后单选，支持搜索。
- 组包方式：文本输入框。
- 校验：三个字段均必填；同一个“安卓版本 + 芯片型号”组合只能存在一条映射。
- 当被引用的安卓版本或芯片型号后续被删除时，已保存映射继续显示历史值，但新增或编辑时只能选择当前有效值。

统一枚举注册表新增两个类型，继续沿用现有本地持久化、序号、增删改、权限和错误提示机制。存储升级时保留用户已有的所有枚举数据，只为新类型补充空数组。

## 3. 联合计划字段映射

联合项目空间“tOS&整机1+N项目计划”固定信息列调整如下：

- 原“SOC平台”改名为“芯片编码”。
- “芯片编码”读取整机项目的芯片编码字段。
- “组包方式”使用整机项目的“安卓版本 + 芯片型号”与配置中心映射进行精确匹配。
- 匹配前统一去除首尾空格；不做模糊匹配。
- 项目字段缺失、配置未就绪或找不到映射时显示 `/`，不阻断联合计划加载。
- tOS 基准行的芯片编码和组包方式仍显示 `/`。

映射只影响展示，不把组包方式反写到整机项目基础信息。

## 4. 锁定数据模型

锁定对象是一条联合计划整机行，唯一键为：

`整机项目ID + tOS项目ID + tOS版本号`

每条锁定记录保存：

- 行唯一键
- 整机项目 ID
- tOS 项目 ID
- tOS 版本号
- 锁定人
- 锁定时间

锁定记录归联合计划状态管理并持久化。存储版本升级时，旧数据默认没有任何锁定行。项目或版本行不再存在时，孤立记录不参与展示和权限判断。

## 5. 选择与批量操作交互

### 5.1 可见性

- 当前用户是至少一个相关 tOS 版本项目的版本项目经理时，显示表格最前方 Checkbox 选择列。
- 超级管理员始终显示 Checkbox 选择列，并可选择全部整机项目行。
- 仅为整机项目 SPM、且不是版本项目经理或超级管理员时，不显示 Checkbox 选择列。
- tOS 基准行不可选择。

### 5.2 可选择范围

- 版本项目经理只能选择自己负责的 tOS 项目下的整机项目行，其他整机行的 Checkbox 禁用。
- 超级管理员可以选择所有整机项目行。
- 选择范围基于当前筛选结果；筛选条件变化后，移除已经不在当前结果中的选择。

### 5.3 操作区

- 操作区位于筛选行最右侧。
- 未选择任何项目时，整个操作区不显示。
- 选择至少一行后，依次显示：`已勾选 xx 个项目 / 锁定 / 解锁`。
- 锁定、解锁操作均允许混合选择；已经处于目标状态的行按幂等方式保持不变。

### 5.4 二次确认

点击“锁定”或“解锁”后弹出确认框：

- 标题明确本次动作。
- 内容逐行列出 `tOS版本号 + 项目名称`。
- 取消不修改数据并保留当前选择。
- 确认成功后批量更新锁定状态、给出成功提示并清空选择，操作区随之隐藏。
- 若确认时权限或数据已变化，只处理仍有权限且仍存在的行，并对未处理数量给出明确提示。

## 6. 锁定展示与编辑权限

### 6.1 锁定标识

- 已锁定整机行在项目名称左上角显示统一线性锁图标。
- 图标提供“已锁定”提示和可访问文本，不仅依赖颜色表达状态。
- tOS 基准行不显示锁图标。

### 6.2 编辑权限矩阵

| 行状态 | 整机项目 SPM | 对应 tOS 版本项目经理 | 超级管理员 |
| --- | --- | --- | --- |
| 未锁定 | 可编辑 | 可编辑 | 可编辑 |
| 已锁定 | 不可编辑 | 可编辑 | 可编辑 |

“可编辑”同时覆盖 `1+N转测类型` 和后续日期字段。用户同时拥有多个角色时按最高权限判断。

锁定/解锁权限：

- 对应 tOS 版本项目经理可操作自己负责的 tOS 项目行。
- 超级管理员可操作全部整机项目行。
- 整机项目 SPM 不可锁定或解锁。

## 7. 横版视图版本发布时间与修订版本

### 7.1 版本发布时间

- 所有支持一级计划横版视图的项目空间，在版本单元格中使用两行展示。
- 已发布版本第一行显示 `Vxx`，第二行显示该版本实际发布时间，格式为 `YYYY-MM-DD`。
- 发布修订版本时记录当前发布时间；日期展示统一按上海业务日期格式化。
- 初始 Mock 已发布版本补充确定的发布时间，以便直接验证展示效果。
- 历史已发布版本没有发布时间时第二行显示 `-`，不得使用创建时间或当前日期伪造。
- 修订版本第一行显示 `Vxx`，第二行显示“修订中”。

### 7.2 基础信息横版视图

- 基础信息中的一级计划横版视图保持只读。
- 展示顺序固定为：最新已发布版本、修订版本（存在时）、实际。
- 修订版本紧跟在最新已发布版本下面，并展示当前修订快照中的计划日期。
- 基础信息中的修订版本即使当前用户拥有编辑权限也不得编辑。
- 没有修订版本时保持“最新已发布版本 + 实际”两行结构。
- 计划模块中的横版视图继续遵循现有修订版本编辑权限，仅增加版本发布时间的第二行展示，不改变版本排序和日期编辑规则。

## 8. 项目列表状态清理

- 项目列表的项目状态快捷项只读取当前项目类型对应的有效状态枚举，不再拼入 Mock 数据或历史数据中出现的旧状态。
- 整机产品项目有效状态：`待立项、在研、上市、EOS、转维、已取消、已暂停`。
- tOS 版本项目和能力建设项目有效状态：`在研、已完成`。
- 技术项目有效状态：`进行中、已完成、暂停、已取消`。
- 刷新全部初始 Mock：整机项目的“暂停”改为“已暂停”，“规划中”改为“待立项”；tOS/能力建设项目的旧状态按当前进度改为“在研”或“已完成”；技术项目的“在研、筹备中、EOS、已迁移”等旧状态按当前进度改为“进行中”或“已完成”。
- Mock 刷新不覆盖浏览器中用户已创建的项目。若历史项目仍保存旧状态，项目本身继续显示原值，但该旧值不再作为可选筛选项；用户编辑后只能选择当前有效状态。
- 项目状态数量只统计当前展示项目；旧状态项目计入“全部”，但不会生成已停用状态快捷入口。

## 9. 代码边界

- 枚举类型、行结构、校验、迁移与消费逻辑继续位于统一枚举模块。
- 组包映射封装为无副作用查询函数，联合计划只消费映射结果。
- 锁定记录、迁移和批量操作位于 MR 版本计划状态模块。
- 权限判断扩展现有 MR 权限函数，避免在表格单元格中重复角色逻辑。
- 联合计划组件仅负责选择状态、确认交互和渲染。
- 一级计划版本模型补充可选发布时间；发布动作负责写入，横版视图只负责格式化展示。
- 基础信息横版视图复用修订快照，但通过展示面参数强制只读，不能复用计划模块的可编辑入口。

不引入后端接口；本阶段仍使用前端 Mock 和本地持久化。

## 10. 验收与回归

### 10.1 自动契约

- 新枚举类型、列名、行结构和存储迁移。
- 安卓版本与芯片型号下拉来源。
- 组包方式组合唯一校验、空值校验和历史值保留。
- 芯片编码读取和组包方式精确映射、无映射回退 `/`。
- 锁定状态存取、批量幂等、旧状态迁移。
- 未锁定与已锁定权限矩阵。
- 超级管理员全选范围、版本项目经理负责范围、SPM 无批量权限。
- 发布动作写入版本发布时间，历史缺失值不被伪造。
- 基础信息横版版本选择顺序为最新已发布、修订中、实际，并且修订行不可编辑。
- 各项目类型状态快捷项仅包含当前配置枚举；全部初始 Mock 状态均属于对应项目类型的有效集合。

### 10.2 浏览器验收

1. 配置中心可以新增、编辑和删除安卓版本。
2. 组包方式弹窗使用两个可搜索下拉和一个文本输入，重复组合会阻止保存。
3. 联合计划显示“芯片编码”，并在映射存在和不存在时分别显示配置值与 `/`。
4. SPM 看不到选择列；版本项目经理只能选择自己负责范围；超级管理员可选择全部整机行。
5. 未勾选时批量操作区隐藏；勾选后显示正确数量。
6. 锁定和解锁二次确认框完整列出版本号与项目名称。
7. 锁图标、锁定后 SPM 禁用、版本项目经理和超级管理员可编辑均符合权限矩阵。
8. 刷新页面后锁定状态仍保留。
9. 现有 MR Mock、日期错误提示、EOS 隐藏、项目跳转和横竖视图回归通过。
10. 计划横版已发布版本在 `Vxx` 下显示 `YYYY-MM-DD`，修订版本显示“修订中”。
11. 基础信息横版在存在修订版本时按“最新已发布、修订中、实际”展示，修订行只读；无修订版本时不出现空占位行。
12. 切换整机、tOS、技术和能力建设项目分类时，不再出现已停用状态；Mock 卡片和列表中的状态均为当前有效值。

- TypeScript 类型检查通过。
