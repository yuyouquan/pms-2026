# 项目列表日历、筛选与字段配置统一设计

## 1. 目标与范围

本次迭代统一项目列表顶部操作、筛选结果展示、月历视图与全系统字段配置交互。范围包括：

- 项目列表视图切换顺序与操作按钮布局；
- 项目列表高级筛选条件的标签化展示；
- 项目列表月历视图的视觉和日期规则；
- 全系统 `SortableColumnSettings` 使用方的字段配置样式与即时生效交互。

不调整项目分类、二级分类、项目状态和技术项目类型的现有筛选规则，不新增日视图或周视图，不改变筛选结果的数据口径。

## 2. 项目列表顶部布局

### 2.1 视图切换

视图切换保持胶囊样式，顺序固定为：

1. 列表视图；
2. 日历视图；
3. 卡片视图。

切换视图时继续使用同一套项目分类、二级分类、项目状态、高级筛选条件及“关于我的”结果。列表和卡片切换后分页回到第一页。

### 2.2 操作按钮

右侧操作顺序固定为：

1. 筛选；
2. 字段配置；
3. 全屏；
4. 新增项目。

新增项目改为仅图标按钮，保留 `aria-label="新增项目"` 和 Tooltip。全屏按钮继续仅在支持全屏的列表、日历视图出现；卡片视图不显示全屏按钮。筛选和字段配置保持图标加文字。

### 2.3 “关于我的”

“关于我的”保留为独立复选项，不合并到筛选条件标签中。默认选中，继续按项目权限角色中是否包含当前登录用户筛选。视觉位置位于右侧操作按钮组的下一行，并与右侧边界对齐。

## 3. 筛选条件标签

### 3.1 替换范围

删除项目列表原“快捷筛选”输入框和下拉框行，项目分类、二级分类、项目状态及技术项目类型的快捷选项保持不变。原快捷筛选对应字段仍保留在高级筛选浮层中。

### 3.2 条件展示

所有已生效的高级筛选条件以 UI 稿样式显示：

- 单个标签按“字段名 + 操作符 + 条件值 + 删除图标”组成；
- 标签使用浅紫底、紫色字段名和操作符、红色删除图标；
- 点击删除图标立即删除该条件并刷新结果；
- 点击标签主体打开筛选浮层，并定位到对应条件供修改；
- 条件修改后立即反映到标签和三个项目视图。

### 3.3 单行折叠

- 默认仅显示一行条件；
- 超出可用宽度的条件不换行，显示“+N”汇总标签；
- 存在隐藏条件时显示“展开”按钮；
- 展开后显示全部条件并允许换行，按钮改为“收起”；
- 切换项目分类时清空该分类专属高级筛选条件并自动收起；
- 无筛选条件时不显示空标签或占位文案，筛选区域仍保持稳定高度。

## 4. 月历视图

### 4.1 工具栏

日历只提供月视图。工具栏从左到右为：

- 今天；
- 上个月；
- 下个月；
- 当前年月，例如“2026年8月”。

右侧仅显示“月”状态，不提供日、周切换。

### 4.2 日期网格

- 星期顺序为周一至周日；
- 固定显示 6 周、42 个日期格，完整覆盖月首和月末相邻日期；
- 每个月的 1 号显示“8月1日”“9月1日”等完整月日；
- 其他日期只显示日数字；
- 相邻月份日期使用弱化文字；
- 当天日期使用蓝色圆形高亮；
- 日历整体适配可视区域高度，常规页面无需纵向滚动即可看到完整六周。

### 4.3 节点事件

- 事件使用浅蓝色横条；
- 文本格式为“节点名称 · 项目名称”；
- 点击事件进入对应项目空间；
- 单日默认展示最多 3 条；
- 超出后显示“还有 N 条记录”；
- 完整内容通过 Tooltip 查看。

## 5. 全系统字段配置

### 5.1 统一结构

所有字段配置入口继续复用 `SortableColumnSettings`，浮层结构统一为：

1. 标题“选择要显示的字段”；
2. 右侧“重置默认”；
3. 搜索框，提示“搜索字段”；
4. 可滚动字段列表；
5. 无底部取消、确认按钮。

### 5.2 字段行

每行按以下顺序显示：

- 拖拽手柄；
- 字段名称；
- 必显标识（仅不可隐藏字段）；
- 右侧睁眼或闭眼图标。

所有字段均允许拖拽，包括必显字段。必显字段不可隐藏，眼睛保持睁开状态且点击不改变可见性；普通字段点击眼睛图标切换显示或隐藏。隐藏字段文字弱化，但仍保留在可排序列表中。

### 5.3 即时生效

拖拽、显隐、重置操作均立即写入当前视图的字段配置并刷新对应表格。搜索仅过滤配置列表，不改变字段配置。关闭浮层不回滚已完成操作。

## 6. 数据流与状态

- 高级筛选继续使用现有 `AnyFilterCondition[]` 作为唯一条件源；标签只负责展示和删除，不维护第二份筛选状态；
- 表格、卡片、日历继续消费同一个过滤结果；
- “关于我的”继续使用独立布尔状态，并与高级筛选结果取交集；
- 字段配置继续使用 `SortableColumnSettingsValue` 的 `order` 与 `visible`；
- 必显字段是否可隐藏由 `hideable === false` 决定，固定列行为继续由列定义的 `fixed` 决定。

## 7. 响应式与无障碍

- 顶部操作按钮不能覆盖分类选项；窄屏时条件标签区域优先折叠为“+N”；
- 新增项目、全屏和显隐图标均提供 Tooltip 与明确 `aria-label`；
- 展开/收起按钮提供 `aria-expanded`；
- 字段拖拽继续支持键盘排序；
- 颜色之外同时使用图标、文字或状态标签表达显隐和必显状态。

## 8. 验收与测试

### 8.1 项目列表

- 视图顺序为列表、日历、卡片；
- 操作顺序为筛选、字段配置、全屏、新增项目；
- 新增项目仅显示图标；
- “关于我的”位于操作按钮下一行且默认选中；
- 删除原快捷筛选控件；
- 筛选条件标签默认单行，支持 +N、展开、收起和单条删除；
- 三种视图使用同一过滤结果。

### 8.2 日历

- 周一为每周第一列；
- 月初 1 号显示完整月日；
- 今天高亮；
- 固定六周完整显示；
- 节点事件内容、溢出数量及项目跳转正确。

### 8.3 字段配置

- 所有入口标题、搜索、重置、列表样式一致；
- 必显字段可拖拽但不可隐藏；
- 普通字段可显隐；
- 操作立即生效，无取消和确认按钮；
- 搜索、拖拽键盘操作和空结果状态可用。

### 8.4 回归验证

执行仓库既有字段配置、项目列表、浮层、技术项目、权限矩阵契约测试，以及 `npx tsc --noEmit`、`npm run build` 和浏览器实测。
