# tOS 路标视觉还原与筛选修复设计

## 目标

以用户提供的六张 UI 定稿图为唯一视觉基准，收紧 tOS 路标的页面层级、工具栏、筛选面板和版本演进卡片，并恢复高级筛选的完整操作链路。

## 交互定稿

- 视图切换位于内容面板上方；内容面板使用白色实体底、紫色顶部描边和紧凑间距。
- 表单视图和版本演进视图共用品牌、产品类型快捷筛选；高级筛选条件以标签形式显示在工具栏下方。
- 高级筛选使用 432px 紧凑浮层，字段、条件、值、删除按钮单行排列。编辑中的不完整条件保留在浮层草稿中，只有完整条件参与数据过滤；重置、删除立即作用于结果。
- 版本演进卡片标题保持“市场名（项目名）”，右侧显示版本类型与 New/Old 标签。
- 卡片默认详情只显示芯片平台、STR5 时间和上市时间；预估日期沿用时钟图标提示。
- 点击卡片打开项目详情弹窗，展示该项目在 tOS 路标中的全部字段。卡片内的历史、冲突、编辑、删除操作不触发详情弹窗。

## 数据与权限

- 详情弹窗只读取现有 `RoadmapProjectRow`，不新增持久化字段。
- 正式项目继续只读；待规划项目的编辑、删除继续沿用现有权限判断。
- 快捷筛选与高级筛选继续共用 `roadmap.filters`，避免两套筛选状态分叉。

## 验收

- 选择高级筛选字段后，字段不会被重置；选值后表格和演进列立即过滤。
- 演进默认卡片不再显示起步 RAM、开发模式等额外字段。
- 点击任一卡片均能打开完整详情；点击卡片操作按钮只执行对应操作。
- 在 1440px 与 1920px 宽度下，工具栏不换行，演进列可横向滚动。
