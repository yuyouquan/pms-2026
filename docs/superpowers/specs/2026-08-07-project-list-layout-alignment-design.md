# 项目列表筛选区与字段配置对齐优化设计

## 目标

修复项目列表筛选区的垂直错位，以及字段配置中显隐按钮横向位置不一致的问题。仅调整布局和样式，不改变筛选数据、权限判断、字段显隐和拖拽逻辑。

## 筛选区布局

- 整机产品项目和 tOS 版本项目：将“关于我的”放入“二级分类”同行，并固定在该行最右侧。
- 技术项目没有二级分类：将“关于我的”放入“项目类型”同行，并固定在该行最右侧。
- 已生效筛选条件单独占据一行，固定显示在“项目状态”行之后；技术项目中仍位于状态行之后，不与项目类型行混排。
- 条件标签从筛选标签内容区的起始位置对齐，保留现有单行收起、`+N`、展开/收起和即时删除交互。
- 项目分类、二级分类、项目状态和项目类型的筛选逻辑保持不变。

## 字段配置布局

- 每个字段行固定为四列：拖拽手柄、字段名称、必显标记、显隐按钮。
- 显隐按钮始终占据最后一列并贴齐浮层右侧。
- 非必显字段仍保留“必显标记”列的空间，避免显隐按钮左移。
- 必显字段可拖拽但不可隐藏；普通字段保持即时显示/隐藏。

## 验证

- 切换整机、tOS、技术项目，确认“关于我的”分别位于二级分类或项目类型同行右侧。
- 新增筛选条件，确认标签位于项目状态下方，并验证删除、展开和收起。
- 打开字段配置，检查必显与非必显字段的眼睛按钮在同一垂直线上。
- 运行项目列表、字段配置契约测试和 TypeScript 类型检查。
