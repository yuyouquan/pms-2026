# 项目列表选中态、固定列与紧凑控件设计

## 目标

在不改动项目列表数据、筛选逻辑和页面结构的前提下，解决项目列表固定列表头与内容列偏差，统一项目行与产品系列的选中反馈，并将项目列表中的下拉框、文本输入框和日期输入收敛为紧凑尺寸。

## 范围

- 项目列表的列表视图，包括整机产品、tOS 版本和技术项目表格。
- 项目列表顶部快捷筛选与项目筛选悬浮框。
- 不修改卡片、日历视图的数据规则，不重做通用 Ant Design 表格。

## 设计

### 固定列尺寸契约

- 每个项目列表字段的 `width` 是列宽唯一来源。
- 渲染列、Ant Design `colgroup`、固定列表头和固定内容单元格共同消费同一宽度；不得通过独立 CSS 宽度补偿。
- `产品系列` 和各项目类型的名称列继续固定在左侧。
- `产品系列` 单行省略，完整值通过 Tooltip 和可访问名称提供。
- 固定列分隔阴影只负责表达滚动边界，不改变列的可见宽度。

### 选中与交互状态

- 项目行使用显式选中 key。选中后整行采用浅紫状态面，并在左侧提供细强调线；固定列与非固定列使用完全一致的背景。
- 产品系列展开时，其合并单元格使用同色系的弱选中状态；展开按钮内部不再保留白色块。
- hover、focus-visible、pressed 和 selected 状态保持稳定尺寸，过渡时长为 160ms；减少动态效果设置下取消过渡。
- 产品系列按钮继续支持键盘操作和 `aria-expanded`。

### 紧凑筛选控件

- 项目列表快捷筛选中的 `Input`、`Select` 使用 `size="small"`。
- 筛选悬浮框中的 `Input`、`Select`、`DatePicker` 使用 `size="small"`，删除按钮与控件高度对齐。
- 多选控件保持单行，超出内容显示数量而不换行。
- 仅在项目列表作用域收紧尺寸，不修改全局表单和项目空间表单。

## 状态与数据流

- 选中行 key 由 `ProjectSummaryTable` 本地维护；筛选、切换项目类型或当前行不再存在时清理无效选中。
- 产品系列的展开/收起继续由现有 `collapsedGroups` 管理，样式根据展开状态派生。
- 行点击仍调用现有 `onViewRow` 或 `onViewProject`，不改变导航与权限逻辑。

## 验证

- 增加源码契约，验证固定列宽只从字段定义生成、紧凑尺寸和选中类存在。
- 验证整机产品系列展开/收起、项目行 hover/选中以及横向滚动时表头和内容边界对齐。
- 验证快捷筛选与筛选悬浮框控件高度一致，多选不换行。
- 运行项目列表专项脚本、`npx tsc --noEmit`、`npm run build` 和浏览器检查。

## 非目标

- 不新增行多选、批量操作或持久化选中记录。
- 不改变项目列表列设置、筛选条件语义或项目分类数量计算。
- 不处理项目空间、计划表格和配置中心的控件尺寸。
