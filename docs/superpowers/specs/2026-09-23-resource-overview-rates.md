# 项目空间资源总览与双执行率修订

本次要求取代 2026-09-22 看板规则中“累计执行率分子另外截至今天”和“全生命周期仅用费用作为主百分比”的约定。

## 入口与交互

- 项目空间—资源首个 Tab 名称为「总览」，移除「项目资源看板／人月与费用分析」标题行。
- 重置筛选和导出保留在筛选栏右侧，继续执行资源导出权限检查。
- 详情 Tab 按「部门投入明细」「工时投入明细」顺序，默认部门投入明细。
- 来源仅取正式版本，版本号在卡片标题右侧；不改变权限、锁定或版本状态规则。

## 人月与总费用

投入、偏差和执行率均按人月在上、费用在下展示。费用统一包含人力费用与非人力费用，万元 = 人月 × 万元/人月费率 + 非人力元 / 10000。

累计预估人月仍依次选择正式项目预算、正式年度预算、正式项目概算，按项目选定一个来源，部门阶段投入乘里程碑间已过自然日比例。人工修改月度人力不反向影响累计预估。

累计预估总费用 = 累计预估人月 × 费率 + 来源版本截至今天的非人力计划费用。过去月份全额计入，当月按截至今天（含当天）周一至周五天数 / 当月周一至周五总天数折算；未来月份和非人力投入范围外的隐藏月份不计入。该预计费用沿用现有预算工作日折算方式，与实际 IPM 工时按来源日历核算相互独立。

## 指标公式

| 指标 | 人月主指标 | 费用辅助指标 |
| --- | --- | --- |
| 概算→预算偏差 | (预算人月−概算人月)/概算人月 | (预算总费用−概算总费用)/概算总费用 |
| 累至今日执行率 | 项目核算人月/累计预估人月 | 项目核算总费用/累计预估总费用 |
| 全生命周期预算执行率 | 项目核算人月/项目预算人月 | 项目核算总费用/项目预算总费用 |

两种执行率分子始终等于当前页面「项目核算」卡片/列，不另行取截至今日实际。核算及年度/概算/预算遵循部门、日期筛选；累计预估分母只随部门筛选和今天变化。当前 Mock 覆盖范围内的未来记录若仍显示在核算中，也计入两种执行率。

卡片、部门行、合计行、Excel 使用同一口径；合计百分比使用合计分子/合计分母，不能平均行百分比。人月、费用分别计算，允许不同，也可能因费用构成相同而相等。各自分母为零或缺失显示「—」，各自超100%标红。

仅非人力费用的部门保留，零人月分母不影响费用率计算。二级部门对应多个一级部门时，非人力归入「未归属一级部门」，不得重复计入。
