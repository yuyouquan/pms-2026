# 项目路标紧凑交互设计

## 背景与目标

当前项目路标顶部工具栏占用空间过大，tOS 版本选择与表格标题重复，版本目标展开后会持续挤压项目内容。同时，品牌和产品类型存在快捷筛选与筛选抽屉两套状态，容易产生认知冲突。

本次改造保持项目路标既有领域规则、数据来源、权限与紫色液态玻璃视觉不变，只优化信息密度和视图操作效率。

## 设计原则

- 桌面数据看板优先展示业务内容，控制区保持紧凑但仍有清晰焦点态。
- 同一个筛选字段只能有一个生效状态，快捷筛选和抽屉不得互相叠加。
- 折叠和全屏属于临时视图状态，不写入持久化业务数据。
- 动画控制在 150–250ms，并遵守 `prefers-reduced-motion`。

## 工具栏与表格标题

顶部工具栏改为紧凑密度：控制高度约 36px、容器纵向内边距 8px、组内间距 6–8px。保留视图切换、品牌、产品类型、修改记录、tOS 版本维护、创建待规划项目、筛选、列设置，并增加当前视图的全屏按钮。

表单视图不再在工具栏显示 tOS 选择器。选择器移动到表格上方标题行左侧，替换当前静态的版本标题；右侧继续显示项目数量和目标相关操作。

表格中 `tOS版本` 列在可见时固定在最左侧，横向滚动时保持可见。操作列继续固定在最右侧；正常项目的操作单元格为空，不再显示“只读”，待规划项目仍显示编辑和删除。

## 版本目标编辑与展示

版本目标维护改为一个多行文本框。编辑时将历史目标内容按换行合并；保存时将完整文本作为一段目标内容保存，只判断整体是否为空，不拆行、不添加项目符号、不删除内部空行。表单视图和版本演进视图使用 `white-space: pre-wrap` 原样展示文本。

目标默认展开：

- 表单视图支持当前版本目标的展开/折叠，折叠后只保留紧凑标题行。
- 版本演进视图每个版本目标支持单独展开/折叠。
- 版本演进工具栏增加“一键收起全部目标 / 展开全部目标”。单个版本操作后，全局按钮根据当前状态提供下一步动作。
- 没有目标的版本不渲染空目标区域。

## 全屏交互

表单视图和版本演进视图共用应用内全屏能力。进入后，项目路标容器固定覆盖浏览器内容区域，隐藏外围项目视图信息，工具栏吸顶到窗口顶部，内容区占满剩余高度。按钮切换为“退出全屏”，按 `Esc` 也可退出。

抽屉、弹窗和确认框继续显示在全屏容器上方。退出全屏时保留当前视图、筛选、滚动和折叠状态；离开项目路标模块时自动退出。

## 筛选联动

品牌和产品类型快捷筛选不再作为独立的第二层过滤，而是直接读写筛选抽屉的 `filters` 条件：

- 选择具体快捷值：新增或替换对应字段为 `equals` 条件。
- 选择“全部”：删除对应字段的筛选条件。
- 抽屉应用 `equals` 条件：快捷筛选同步选中对应值。
- 抽屉应用 `notEquals`、`isEmpty` 或 `isNotEmpty`：快捷筛选显示只读的“自定义”状态。
- 在“自定义”状态点击具体快捷值：用新的 `equals` 条件替换原条件；点击“全部”清除原条件。

筛选数量徽标统计统一后的抽屉条件数量。品牌、产品类型和其他字段仍按 AND 关系过滤。

为兼容已有本地持久化数据，模块加载时将旧的 `brandFilter`、`productTypeFilter` 迁移为对应 `equals` 条件，再重置旧快捷字段；后续只使用统一条件源。

## 组件边界

- `RoadmapToolbar`：紧凑控制区、快捷筛选展示、全屏和版本演进目标批量折叠入口。
- `ProjectRoadmapModule`：管理全屏、目标折叠临时状态，并将快捷筛选转换为统一条件。
- `RoadmapTableView`：标题行 tOS 选择器、固定首列、目标折叠和空白正常项目操作列。
- `RoadmapEvolutionView`：单版本目标折叠、批量折叠状态和全屏高度适配。
- `TosTargetEditor`：单一多行文本编辑与原样保存。
- `roadmapFilters` / `roadmapStore`：快捷筛选条件转换、旧状态兼容和统一筛选执行。

## 异常与边界

- 无 tOS 版本时，标题选择器禁用并保留既有空状态。
- 删除当前版本后，选择器继续使用既有回退规则选择最高语义版本。
- 全屏期间打开抽屉或弹窗时，`Esc` 优先由最上层浮层处理；没有浮层时退出全屏。
- 目标仅包含空白字符时视为清空；内部换行和空行保留。
- 列设置隐藏 `tOS版本` 后不强制恢复该列；再次显示时自动固定在最左侧。

## 验证范围

- 规则脚本覆盖快捷筛选双向同步、旧状态迁移、目标文本保真、固定列和正常项目空操作。
- TypeScript 全量检查与 Next.js 生产构建通过。
- 浏览器验证 1440px、1024px 和 375px；检查紧凑工具栏、横向表格滚动、目标单独/批量折叠、全屏与 `Esc`、筛选抽屉双向联动。
- 键盘验证全屏、折叠、筛选和目标编辑按钮具有可见焦点及正确 `aria-expanded` / `aria-pressed` 状态。
