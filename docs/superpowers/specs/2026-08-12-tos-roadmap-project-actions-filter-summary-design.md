# tOS 路标项目级操作与筛选摘要设计

## 目标

根据 2026-08-12 UI 稿调整 tOS 路标视图，在不改变现有项目、冲突和修改记录数据模型的前提下：

- 将冲突处理和历史记录从全局工具栏下沉到单个项目。
- 在工具栏下方直接展示已生效的筛选条件。
- 在版本演进卡片标题右侧展示版本类型和产品类型 Tag。

## 范围与边界

- 保留表单视图、版本演进视图、筛选抽屉、列设置、tOS 版本维护、新建项目和全屏能力。
- 保留现有冲突计算与修改记录数据；本次仅改变入口和过滤范围。
- 不新增后端接口，不改变持久化结构。
- 正式项目继续只读；待规划项目继续受现有编辑权限控制。

## 项目级操作

### 表单视图

- 顶部工具栏移除全局“冲突”和“记录”按钮。
- 项目行悬浮或键盘聚焦时显示项目级操作。
- 正式项目允许查看该项目历史记录，不显示编辑和删除。
- 待规划项目在有编辑权限时显示编辑、历史记录和删除。
- 仅存在冲突的待规划项目显示冲突入口；点击后只打开该项目对应的冲突组。
- 操作按钮使用紧凑图标并提供 Tooltip 与可访问名称，不显示长文案。

### 版本演进视图

- 保留当前紧凑“操作”图标和折叠动画。
- 展开操作区后提供编辑、历史记录和删除；冲突入口只在冲突项目出现。
- 项目级历史记录只展示当前项目的日志。
- 正式项目卡片继续只读，不出现编辑和删除；如需要进入历史记录，通过独立历史图标提供。

## 历史记录与冲突抽屉

- 修改记录抽屉新增可选项目范围参数。项目级打开时，项目查询条件锁定为当前项目，并只展示该项目记录。
- 冲突抽屉新增可选冲突 key。项目级打开时仅展示匹配的一个冲突组。
- 删除待规划冲突项目成功后，关闭或刷新当前冲突抽屉，并同步更新表格、演进卡片和冲突状态。

## 筛选条件摘要

- 筛选抽屉继续作为新增和编辑条件的唯一入口。
- 主工具栏下方新增已应用条件区，每个条件使用胶囊展示“字段、运算符、值”。
- 可选字段的多个值使用精简文本表示；超长内容省略并通过 Tooltip 展示完整值。
- 每个胶囊支持单独删除；条件较多时默认单行收起并显示剩余数量。
- 提供“展开/收起”和“清空”操作；没有条件时不占用额外高度。
- 筛选按钮显示当前有效条件数量；快捷品牌、产品类型与筛选抽屉保持现有双向联动。

## 版本演进卡片

- 标题保持“市场名（项目显示名）”，不修改现有命名规则。
- 标题右侧依次展示版本类型 Tag 和产品类型 Tag。
- 版本类型沿用现有颜色：Full 蓝色、Slim 金色、Go 青色。
- 产品类型文案：新品显示 `New`，老品显示 `Old`；New 使用橙红色，Old 使用中性灰色。
- 版本类型已经在标题区展示后，不在卡片详情区重复显示；产品类型不进入可取消的字段配置。
- 标题过长时优先省略标题，两个 Tag 保持完整、单行、不换行。

## 状态与数据流

- `ProjectRoadmapModule` 继续持有抽屉打开状态，并新增当前项目 ID、当前冲突 key。
- `RoadmapToolbar` 只负责视图、快捷筛选、目标、版本维护、新建、筛选、字段配置和全屏。
- `RoadmapTableView` 与 `RoadmapProjectCard` 通过回调上报查看历史和处理冲突事件。
- 已应用条件摘要直接读取 roadmap store 中已生效的 `filters`，删除或清空后调用现有 `setFilters`。

## 错误与权限

- 找不到项目日志时展示该项目暂无记录，不回退到全局记录。
- 冲突已被其他操作解决时展示暂无冲突并关闭无效入口。
- 编辑和删除继续使用现有权限判断；查看历史遵循路标查看权限。
- 图标按钮支持键盘聚焦，Tooltip 不作为唯一的可访问标签。

## 验证重点

- 顶部工具栏不再出现全局冲突和记录入口。
- 正式项目、普通待规划项目、冲突待规划项目的操作集合符合边界。
- 项目级历史和冲突抽屉不会混入其他项目数据。
- 筛选胶囊能正确显示、单删、展开/收起和清空，并与抽屉及快捷筛选同步。
- 演进卡片标题不变，右侧 Tag 顺序、颜色和溢出行为符合 UI 稿。
- 表单行悬浮、演进卡片操作展开和筛选摘要展开动画无明显跳动。
