# 项目日历共享筛选设计

## 目标

补齐项目列表日历视图快捷筛选行最右侧的“筛选”按钮，使日历与列表、卡片共用相同的筛选条件和筛选结果。

## 问题根因

筛选按钮和悬浮筛选面板由 `ProjectSummaryTable` 渲染并通过 `toolbarHost` 注入快捷筛选行。列表视图直接挂载该组件，卡片视图挂载 `showTable={false}` 的控制器实例；日历分支没有挂载控制器，因此按钮和筛选面板都不存在。

## 设计

- 日历分支挂载与当前项目类型匹配的 `ProjectSummaryTable` 控制器实例。
- 控制器设置 `showTable={false}`、`showQuickFilters={false}`，只负责向现有 `toolbarHost` 注入筛选操作。
- 标准项目继续使用 `summaryFilters / setSummaryFilters`；技术项目继续使用 `technicalFilters / setTechnicalFilters`。
- 日历节点继续由现有已筛选 rows 生成，筛选条件修改后立即触发日历结果更新。
- 为共享控制器增加明确的工具栏能力开关。日历视图设置为只显示“筛选”，不显示“列设置”；列表和卡片视图保持“筛选 + 列设置”。
- 不复制筛选面板、不新增日历专属筛选状态，也不修改筛选字段来源。

## 交互

- “筛选”按钮位于快捷筛选同行最右侧，与其他视图位置一致。
- 已启用高级筛选时按钮继续使用当前主色状态。
- 筛选面板沿用悬浮框、即时生效、重置、增加条件和删除条件交互。
- 切换列表、卡片和日历视图时保留已设置的筛选条件。

## 验证

- 专项契约验证日历分支挂载无表格控制器并关闭列设置。
- 专项契约验证列表、卡片仍保留原有列设置能力。
- 浏览器验证日历视图快捷筛选行最右侧显示“筛选”且不显示“列设置”。
- 浏览器设置项目名称或状态条件后，日历节点立即随筛选变化；切回列表后条件仍然存在。
- TypeScript 和生产构建通过。
