# 项目资源看板业务改版

依据业务截图和用户已确认口径，主视图按一级部门、二级部门、日期筛选，六张卡同排：项目年度预算、项目概算、项目预算、项目核算、概算→预算偏差、预算执行率。预算默认唯一正式版本，可手动分析其他版本；前三张卡显示版本号及锁定状态。人月为主，费用为辅；偏差和执行率按费用计算且明确标记，偏差=(预算-概算)/概算，执行率=核算/预算，零分母显示破折号。

四类数据使用月度/周度折线图，可切换人月与万元。预算来自月度计划，按当月周一至周五均摊到日期后筛选及周汇总，明确标注折算。核算来自独立 Mock 人天及实际非人力费用，不随选择预算版本改变，不宣称接通 IPM。核算人月逐条按人天/来源当月工作日换算；Mock 工作日使用周一至周五，未来接入 IPM 时采用其返回口径，不使用固定小时常数。

费用=人月×配置费率+非人力元/10000，保持计算精度至展示。工时明细展示日期、人员、两级部门、人天、当月工作日、折算人月、费用及工作内容；实际非人力明细可展开查阅。当前核算覆盖区间以外不补零。没有来源不伪造核算或默认草稿。未归属/歧义一级部门的非人力费用单列归属，避免遗漏或重复。

保留来源跳转、权限和原来的详细分析，将详细分析放入更多分析。导出与筛选、趋势、明细一致。预算数据与核算数据只读计算，绝不回写原始投入。
