# tOS 项目状态映射设计

## 目标

tOS 版本项目在创建、项目列表和项目空间基础信息中统一使用 PMS 状态，并按 IPM 来源状态转换：

| IPM 状态 | PMS 状态 |
| --- | --- |
| 暂停 | 暂停 |
| 已取消 | 已取消 |
| 进行中 | 在研 |
| 已完成 | 已完成 |
| 维护期 | 已完成 |

## 设计

- 新增独立的 tOS 状态映射与选项模块，作为三个界面的唯一状态口径。
- 创建项目时从 IPM 项目条目读取状态，映射后以只读字段展示并保存。
- tOS 项目列表使用 `全部 / 在研 / 已完成 / 暂停 / 已取消` 直接筛选；技术项目继续使用现有聚合筛选。
- 项目空间基础信息展示映射后的状态，编辑时仅允许选择四个 PMS 状态。
- 现有 tOS Mock 项目统一到四个 PMS 状态；其他项目类型的状态映射和筛选不变。

## 验证

- 自动验证五条 IPM 映射、tOS 状态选项，以及创建、列表、基础信息三处接入。
- 运行项目状态验证、现有项目列表验证、TypeScript 类型检查和生产构建。
