# 项目列表主固定列视觉优化设计

## 目标

优化整机产品项目列表中“产品系列”和“项目名称”两列，使分组信息清晰、固定列宽稳定，并消除当前产品系列背景内缩、项目名称表头与内容宽度不一致的问题；同时重做列表、卡片和日历视图切换控件的视觉层级。

## 范围

- 调整项目列表表格视图的主固定列样式和宽度契约，以及三个视图共用的切换控件。
- 不改变产品系列分组、展开收起、进入项目空间和横向滚动逻辑。
- 不改变卡片视图、日历视图、筛选数据或项目数据结构。

## 设计

### 产品系列列

- 固定宽度统一为 `160px`。
- 分组单元格取消全局表格内边距，系列按钮铺满整个单元格，不再形成居中的小色块。
- 展开图标、系列名称和项目数量按统一的左侧基线排列。
- 系列名称保持单行；空间不足时使用省略号，并通过 Tooltip 显示完整名称。
- 展开、悬停和选中状态作用于完整单元格，颜色保持现有紫色体系，但降低背景对比度以避免抢占项目名称的视觉层级。

### 项目名称列

- 固定宽度统一为 `220px`。
- 表头、普通内容单元格和固定列容器采用相同的 `width`、`min-width`、`max-width`、`box-sizing` 和横向内边距。
- 项目名称单行显示；超长名称使用省略号和 Tooltip，避免撑开固定列。
- 固定列右边界使用轻量阴影表达滚动层级，不再造成列宽增加的错觉。

### 选中与交互

- 行点击选中后，背景覆盖整行及固定列，不再只突出产品系列内部按钮。
- 展开收起按钮继续阻止行点击事件，避免切换分组时误进入项目空间。
- 保留键盘焦点轮廓、`aria-expanded` 和 Tooltip。

### 视图切换

- 列表、卡片和日历三项增加语义明确的线性图标，图标与文字始终同行。
- 控件采用 `36px` 高、`10px` 圆角的浅紫灰分段轨道，三项使用一致的高度和横向留白。
- 选中项使用紫色渐变背景、白色文字和克制阴影；未选中项透明，悬停时显示淡紫背景。
- 控件与“新增项目”按钮高度一致，间距保持 `10px`，在分类行右侧形成一个完整操作组。
- 保留 Ant Design `Segmented` 的键盘交互与语义，不自行重写状态逻辑。

## 实现约束

- 使用项目现有 `ProjectSummaryTable` 和 `projectListMatrix` 宽度定义，不引入新的表格组件。
- 使用高于全局 `.pms-table` 单元格规则的局部选择器，确保产品系列 `padding: 0` 不再被后置样式覆盖。
- 宽度规则由字段定义单一来源生成，禁止表头与内容各自维护不同宽度。

## 验证

- 专项契约验证产品系列 `160px`、项目名称 `220px`、分组单元格全宽和文本省略规则。
- 专项契约验证视图切换的图标、`36px` 高度、选中渐变和三项一致布局。
- TypeScript 与生产构建通过。
- 浏览器实测表头和内容的左右边界一致，产品系列背景铺满单元格，展开收起和行点击互不干扰。
