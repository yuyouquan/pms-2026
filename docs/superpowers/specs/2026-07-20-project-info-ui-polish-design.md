# 项目基础信息 UI 优化设计

## 目标

在不改变项目字段定义、权限规则和数据存储方式的前提下，统一整机产品项目与 tOS 版本项目的基础信息视觉与交互。页面参考用户提供的信息卡片样式，兼顾现有 PMS 的浅色企业后台风格和信息密度。

## 范围

- 项目空间的项目名称与核心字段区域。
- 整机项目的计划信息字段展示。
- 基础信息、扩展信息、团队信息分类区域。
- 分类字段显示配置入口。
- 新建项目和编辑项目信息 Modal。

本轮不修改字段 Schema、创建必填规则、字段值来源、项目权限或用户字段偏好的持久化契约。

## 视觉方案

采用轻量企业信息卡片方案，沿用系统现有蓝紫主色，以白色表面、浅灰边框和彩色图标底建立层级。不引入新的字体或图标库，继续使用 Ant Design 图标，避免与现有页面产生视觉割裂。

统一使用 4/8px 间距节奏、10–12px 圆角、低强度阴影和 180–240ms 的缓动。动效仅用于展开收起、悬停反馈和抽屉进入；`prefers-reduced-motion` 下关闭非必要动画。

## 页面结构

### 项目名称与核心字段

- 移除“核心板块”文案，Card 标题显示“项目名称”，副标题显示实际项目名。
- 整机和 tOS 的核心字段都只占一行。
- 桌面端按字段数量平均分配宽度；可用宽度不足时保持一行并允许横向滚动，不换行。
- 字段采用紧凑信息块，保留彩色状态提示，但不只依赖颜色表达状态。
- 编辑、申请转维、状态与健康状态操作继续位于标题右侧，权限行为不变。

### 计划信息

- 将计划开始时间、计划结束时间、开发周期与六个新增市场字段统一为同一种指标卡样式。
- 桌面端使用五列网格，共九个字段，按 5+4 两行展示。
- 指标卡包含字段名、值和必要的图标或状态标签。
- “取消暂停时间”在“是否取消暂停”为否时显示 `-`，仍占固定网格位置，避免布局跳动。
- 1024px 以下自适应为三列或两列，但不改变字段顺序。

### 信息分类

- 基础信息、扩展信息、团队信息继续保持可折叠，不改变字段显隐逻辑。
- 分类头部采用彩色图标容器、标题、数量徽标和右侧“配置字段”按钮。
- 基础信息和扩展信息使用规则字段网格：标签置顶、值加深，单元格用浅分隔线组织。
- 团队信息使用人员卡片：头像、姓名、角色标签，空值仍显示占位。
- 折叠面板悬停时轻微提升边框与阴影；展开内容使用淡入和轻微上移动效。

## 字段配置抽屉

- 以 420px 右侧 Drawer 替换当前 Popover，交互参考一级计划的“列设置”。
- 抽屉标题为“配置字段 · {分类名称}”。
- 字段纵向排列，包含必显/不可隐藏状态提示和条件显示说明。
- 打开抽屉时复制当前配置为临时草稿；点击“确定”后写入既有用户+项目偏好仓储。
- “取消”不保存本次调整；“重置默认”恢复 Schema 的默认显示字段。
- 无配置权限时按钮保持禁用，并显示现有权限提示。

## 新建与编辑 Modal

- Modal 桌面宽度扩大到 1240px，内容区保持纵向滚动。
- 通用字段、核心信息和分类字段统一为三列。
- 1100px 以下变为两列，768px 以下变为一列。
- 分组使用轻背景与边框区分，标题包含图标、分类名和字段数量。
- JIRA 等复杂字段继续占整行；条件字段显隐和校验聚焦逻辑不变。
- 只读来源字段使用浅灰蓝背景，与可编辑字段清晰区分。
- Modal 关闭确认、提交 loading、首个错误字段定位行为保持不变。

## 组件调整

- `TargetProjectInformationView`：调整标题和核心字段单行布局。
- `ProjectInfoSections`：负责分类卡片、字段网格和展开动效。
- `FieldVisibilityPicker`：重构为内部管理草稿状态的 Drawer。
- `ProjectInfoModal`：调整宽度、三列布局和分组呈现。
- `ProjectSpaceContainer`：将整机计划信息改为统一指标网格。
- `globals.css`：补充语义化样式、响应式规则和 reduced-motion 处理。

## 数据与兼容性

- 不新增 Store 字段或修改项目数据结构。
- 字段显隐仍通过 `useProjectFieldVisibility` 保存，Drawer 只改变提交时机。
- 非整机/tOS 项目保持原展示流程。
- 现有字段为空时统一显示 `-`，避免空白卡片和布局塌陷。

## 验收

- 整机核心字段在桌面宽度下一行展示，窄屏不换行且可滚动。
- 计划信息九个字段在桌面端两行显示，视觉样式一致。
- 三个分类头部、字段网格、团队卡片及展开动效符合参考图方向。
- 配置字段以 Drawer 打开，取消不保存、确定保存、重置默认有效。
- 新建与编辑 Modal 桌面端三列，字段回填和校验不受影响。
- 通过 TypeScript 检查、生产构建和整机/tOS 关键浏览器路径冒烟。
