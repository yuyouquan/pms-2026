# 项目列表视图胶囊切换设计

## 目标

将项目列表的“列表视图 / 卡片视图 / 日历视图”切换器优化为轻量胶囊样式，去除图标，仅保留文字，提升选中状态辨识度与整体精致度，同时保持现有视图切换逻辑和全屏能力不变。

## 视觉方案

- 使用已确认的 A 方案：浅灰紫色胶囊轨道配白色选中胶囊。
- 外层高度为 36px，使用完全圆角、1px 浅色边框和轻微阴影，背景采用低饱和浅灰紫色。
- 三个选项仅显示“列表视图”“卡片视图”“日历视图”文字，不显示任何图标。
- 选中项为白色胶囊、品牌紫文字和柔和阴影；未选中项使用中性灰文字。
- 悬停时文字转为品牌紫，并增加轻微白色背景反馈；键盘聚焦保持清晰可见。
- 选项文字保持单行，三个选项宽度由内容和统一水平内边距决定，避免视觉拥挤。

## 交互与状态

- 继续复用现有 `Segmented` 和 `projectListView` 状态，不新增第二套切换逻辑。
- 点击任一选项立即切换对应视图。
- 保留键盘操作、焦点反馈和 `aria-label`，不因去除图标降低可访问性。
- 切换视图不重置项目分类、二级分类、项目状态、快捷筛选、高级筛选或“关于我的”条件。
- 列表视图和日历视图的全屏入口及全屏状态逻辑不变。

## 实现边界

- 修改 `ProjectListContainer` 中三个选项的标签结构，移除仅供视图切换器使用的图标依赖。
- 修改 `globals.css` 中 `pms-project-list-view-switch` 样式，统一轨道、选项、选中、悬停和焦点状态。
- 不修改视图顺序，仍为“列表视图、卡片视图、日历视图”。
- 不修改项目数据、筛选、列设置、日历、卡片、表格或路由逻辑。

## 验证

- 更新项目列表源码契约：校验三个选项顺序和纯文字结构，禁止视图切换图标回归。
- 校验胶囊轨道、白色选中项、品牌紫文字、悬停及焦点样式存在。
- 运行项目列表相关契约、`npx tsc --noEmit` 和 `npm run build`。
- 浏览器检查三种视图均可切换，筛选状态保持，列表/日历全屏功能不受影响，并确认控制台无新增错误。

## 非目标

- 不改变三种视图的内容布局。
- 不增加新的视图模式或动画框架。
- 不调整快捷筛选、新增项目、筛选及列设置按钮。
