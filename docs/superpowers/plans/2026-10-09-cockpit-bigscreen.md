# 驾驶舱图形化大屏改版

**目标**：解决表格密集、布局松散和教学小字干扰；接入 Apache ECharts，以真实项目资源展示大屏资源驾驶舱。

**设计**：沿用 PMS 紫色品牌与浅色渐变背景、白色卡片，顶部五项投入 + 三项比率，主趋势与环形结构并列，下方分类对比与项目排行并列。首页不渲染表格；资源总览与月度结构通过明细抽屉访问。保留原 Header、技术运营空白、权限和项目资源跳转。增加原生全屏，失败有反馈，Esc 可退出。教学文本从可见页面移除，键盘提示仅提供给读屏。Remotion 保留卡片和数字动效；ECharts 管理图形动效并遵循减少动态效果。

**决策**：延用当前 feature checkout 与真实共享 store，不从 dev 重建；用户已授权自主优化并在本轮明确提出图形化和 ECharts，不重复审批。按用户最新反馈保留图形化大屏结构，配色改为系统原有的紫色与浅色，复用 PMS 语义变量；不采用装饰地图，因为当前数据没有地理含义。

**实现与验收**
- [x] ECharts 按需动态加载 Line/Bar/Pie + SVG renderer，ResizeObserver 生命周期清理。保留 undefined 缺口、负值和原有单位；只做表现层映射。
- [x] 趋势保留图例、期间固定/下钻/返回及键盘操作，去掉可见操作教学。
- [x] 新增环形结构和分类预算/核算对比，分类和项目明细通过可访问按钮打开原总览；月度占比移至抽屉。
- [x] 大屏布局、紧凑八指标和全屏；技术运营空白；共享表格/资源编辑不受影响。
- [x] 回归脚本、tsc、build 顺序验证；浏览器实测 1920/1512/390、全屏/退出、筛选、图例/期间、抽屉/项目返回、权限切换、减少动态效果及控制台；保存截图。
- [x] 独立最终代码审查与差异检查完成；feature 提交、推送及远端一致性由本聊天最终结果核验。

**实现文件**：CockpitEChart.tsx / cockpitEchartsRuntime.ts 管理实例与加载；cockpitChartOptions.ts 为纯图表映射；CockpitChart.tsx 保留趋势交互；CockpitAllocation.tsx 和 CockpitComparison.tsx 为图形面板；HrPipelineContainer.tsx 编排页面、抽屉及全屏；globals.css 仅驾驶舱命名空间；cockpitUi.ts 仅加入明细开关以保留项目往返位置。
