# 项目资源看板实现与验收计划

**目标：** 用年度预算、项目概算、项目预算的实际版本数据构建可筛选、可追溯的资源分析看板。

**已确认口径：** 默认正式版本；没有正式版本则不纳入，允许手动选择其他版本分析。三个预算口径分别比较，不相加。分析选择不修改正式状态。

**实现：** 复用四类资源 store、版本可见性、费率、月度分配与阶段归属规则。分析函数生成统一结果，React 组件展示并通过现有编辑守卫跳转来源。预算项目继续只有年度预算；正式项目的资源首页进入看板。路标及无数据场景给出空状态。

## 指标和边界

- 人力费用 = 当前筛选月度人月 × 配置中心费率（万元/人月）。非人力费用 = 当前版本计划月份内的元金额 / 10000。
- 全周期部门目标从版本部门合计读取；年份视图的人月来自该年已分配月份，不把全周期目标当作年度目标。
- 月均 = 当前筛选人月 / 当前筛选计划月份数，峰值采用该视图的月份。全周期平衡偏差独立于年份筛选显示，并标注口径。
- 阶段结构沿用月度表的月份主阶段归属规则，并明确说明跨阶段月份的归属方法。未归属月份保留为独立项。
- 年度预算来自与当前正式项目绑定且用户可读的预算项目；缺数据不自动创建版本、不混入其他项目。
- 当前数据是计划和预算，不展示实际支出、预算执行率或收益等无来源指标。
