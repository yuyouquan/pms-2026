# 整机 MR 筛选和实际日期验证

## 需求与实现

- 三级 MR 计划增加 tOS 版本号、MR 号文本模糊搜索，以及市场项目下拉多选；条件取交集。横版按市场筛行，竖版按市场筛列；MR 编号来自完整版本集合，不随筛选重排。
- 用户确认在 MR 子任务填写实际开始、实际完成日期，阶段自动汇总。
- 仅管理组/SPM 可在最新已发布版本中编辑上述实际日期。修订版本同步只读；计划日期、子任务结构仍由 MR 计划生成。
- 实际日期按项目、市场及源任务稳定标识保留，MR 计划重算不覆盖；已删除源节点不复活，明确清空的日期不恢复。

## 自动验证

- `verify-machine-mr-level1-projection`：新增回归先确认旧实现丢失实际日期，再验证修复；覆盖模糊组合搜索、市场多选、筛选清空、输入不可变、同步保留/清空、阶段汇总、持久化和删除。
- `verify-level1-shared-business`：覆盖管理组/SPM、普通用户、历史版本和修订版本的实际日期权限；原有结构限制保持。
- `verify-tos-mr-level1-sync`、`verify-level1-plan-governance` 均通过。
- `npx tsc --noEmit`、`npm run build`、`git diff --check` 均通过。
