# 驾驶舱展示与交互优化实施计划

用户已在审查六项建议后明确要求“开始优化”。沿用该设计，在本会话顺序实施和验证。

**Goal:** 对齐驾驶舱和项目资源下钻范围，统一视觉语义，提升分类大屏及窄屏可读性。

**Architecture:** 项目空间导航携带用户、项目、日期、部门和单位选择，不存资源值或权限结果。项目资源继续调用既有计算函数，按实时权限限制部门；仅来源驾驶舱的核对模式使用截至今日的核算和范围内累计口径。普通全周期入口保持既有默认。ECharts 只改变展示，缺失、负值、正式版本和年度绑定规则不变。

**Tech Stack:** Next.js / React / TypeScript / Zustand / Ant Design / ECharts。

- [x] 下钻范围：扩展 ui 导航上下文；项目资源接收上下文，支持多部门、实时权限、当前日期截止、金额主视角和查看全周期。增加真实源值比较、用户项目隔离、未来区间及多部门测试。
- [x] 视觉语义：共享资源指标颜色；趋势、对比、图例和指标卡一致。本月柱/折线增加截至日期标记，完整历史月份不标记，不补未来值。
- [x] 布局与操作：分类视角趋势跨两行，结构与对比在右列，排名占底部整行。摘要突出可用项目数。窄屏用明确月份切换和排名类别下拉；保留键盘和减弱动效行为。
- [x] 验证：运行驾驶舱所有相关 verify 脚本及项目资源业务回归，顺序执行 `npx tsc --noEmit`、`npm run build`；在3038生产预览实际核对来源、往返、期间、月份控制、单位和分类，检查1920/1600/390/320布局、全屏、控制台及技术运营留白。
- [x] 将截图和结果追加到现有 QA 记录，检查差异并提交推送 `codex/feature-cockpit-ux-refinement`，不合入主干或发布。

验收：从同一日期和部门进入项目资源，预算/核算及所选单位可直接核对；查看全周期与普通入口不受遗留上下文影响。分类视角无空白拉伸，八指标桌面同排，四行柱的分隔及统一刻度保留，TOP5不虚构补位，窄屏页面无横向溢出。
