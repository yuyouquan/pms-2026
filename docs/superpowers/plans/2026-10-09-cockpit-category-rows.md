# 项目分类投入分行柱状图

**目标**：按用户参考图将分类投入从堆叠柱改为四行柱状图，逐类直接读数。
**设计**：沿用四类资源核算、筛选、月／周、人月／万元；同一 ECharts 实例内四组 grid/xAxis/yAxis，共用数值范围和期间顺序。紫色柱顶显示一位小数，缺失仍为空，零值显示0.0，负值保留。左侧类型名兼容原系列显示／隐藏操作；按用户追加反馈，在四行间增加三条贯穿类型名和绘图区的横向实线。周数据共享缩放窗口12期；小屏仅图内横向滚动，保持类型名可见。保留点击／键盘固定期间及查看、返回逻辑，不改资源总趋势。
**依据**：用户图一为已选定视觉方案；ECharts 官方多坐标系文档 https://echarts.apache.org/handbook/en/concepts/dataset/ 。
