# 全系统 UI 规范

依据：2026-09-07 用户提供的 tOS 路标参考图，并明确要求所有界面执行。参考图包含缩放和画布边缘，以下为浏览器 100% 下的 CSS 尺寸；黑色画布、左侧设计工具标注和示例业务字段不属于产品规范。

## 字体与密度

| 对象 | 规范 |
| --- | --- |
| 正文、表格数据、表单、导航 | 14px，常规字重，行高 22px |
| 表头、分组标题 | 16px，600，行高 24px |
| 页面标题 | 20px，600，行高 28px |
| 辅助描述、日期副文本、标签 | 12px，行高 18px；不可替代正文 |
| 普通数据行 | 最小 40px，单元格上下 8px、左右 12px |
| 单层表头 | 最小 48px，单元格上下 12px、左右 12px |
| 多级表头 | 每层最小 40px，合并单元格按层数自然增高 |
| 按钮、输入框、选择器、日期框 | 32px，表内编辑同样使用 32px |

多行说明、标签组合、合并行、错误提示按内容增高，不固定裁切。隐藏测量行保持 0 高度。数字、日期使用等宽数字。已有树形缩进、固定列、拖动手柄保留。

## 间距与容器

- 桌面页面：左右 32px、上方 16px、下方 24px；窄屏 16px，不缩小字体。
- 项目空间和配置内容区：24px；卡片内部 16px；弹窗与抽屉主体 24px。
- 模块间距 24px，标题与内容 16px，工具栏与表格 12px，控件间距 8px。
- 工具栏允许换行；宽表在自身区域横向滚动，不撑宽整个页面。
- 分页在表格下方靠右，与表格间隔 24px。
- 主容器白底、圆角 16px；普通分组圆角 8px；控件圆角 6px。

## 颜色与交互

- 沿用项目紫色品牌，表头统一浅紫底和深色文字；表格正文白底、浅色水平分隔线。
- Hover 使用淡紫底；选中使用更深淡紫底；异常保留浅红底与红色边缘/图标，不能被统一样式覆盖。
- 可编辑、禁用、只读、发布/修订、N/A、停止发版维持原业务含义；样式不改变权限。
- 焦点轮廓可见；表头排序、列宽调整、树形展开、全屏和弹层正常工作。

## 执行范围

工作台（计划、转维）、项目列表（各分类、列表/卡片/日历）、联合项目空间、tOS 路标（表格/演进）、项目空间（基础信息、各计划、权限、转维）、配置中心（计划模板、转维模板、枚举、权限）、所有弹窗/抽屉/分享页与空状态。

统一值由主题和共享 CSS 管理；页面只保留布局及业务状态样式。Ant Design 表格、原生横版表格、MR 网格、甘特图必须使用同一字号和间距尺度。验收需同时检查只读、编辑态、错误态及窄屏。

## 必要例外

- 树形连接线、展开图标、拖动手柄、头像字母和必填上标维持各自几何尺寸，不按正文放大；按钮外部交互区域仍执行 32px。
- 甘特条保留 20px、里程碑菱形保留 14px，所属数据行使用 40px；多层时间刻度按每层 40px 计算。
- 日期副文本、角色和部门等元数据采用 12px/18px；任务、责任人、权限项名称及表单内容属于正文，不能套用辅助字号。
- 权限矩阵的开关、组合标签、编辑控件、合并行及多行内容允许行高超过 40px；隐藏列宽测量行保持 0px。
- 弹窗主体统一承担 24px 内边距，路标详情的内部包装不再叠加第二层内边距。视口测量允许不超过 1px 的浏览器舍入差异。
