# 全系统 UI 规范

2026-09-20 更新：以 [Figma 项目管理系统基线](../design/figma-pms-20260920/UI规范.md) 和配套 [design-tokens.json](../design/figma-pms-20260920/design-tokens.json) 为当前视觉合同。覆盖 2026-09-07/09 的样式要求；中文业务字段、枚举、权限、交互及数据合同不变。2026-09-20 用户补充要求：表单之间的行间距统一、紧凑。

## 字体与密度

| 对象 | 当前规范 |
| --- | --- |
| 正文、表单、导航、表格正文、表内链接与编辑文字 | 14px/20px，正文400，标识500 |
| 分组/弹窗标题 | 16px/24px，600（工程补全） |
| 表头、横版行标题、甘特列头与时间刻度 | 14px；表头浅紫 `#F0EFFF`（工程映射），单层48px，多级每层40px |
| 页面标题 | 20px/28px，600（工程补全） |
| 标签 | **12px/16px、500、高24px、左右8px、上下4px、内描边1px**；表内也保持12px |
| 普通单行数据 | **最终行高40px**，左右12px；以20px行高和1px底边校正上下各9.5px |
| 含标签/32px控件的行 | 上下内边距分别收为7.5px/3.5px，使单行仍为40px；多行可增高 |
| 按钮、输入、选择器、日期框 | 32px，圆角6px；按钮文字14px/400，左右16px |

多行说明、组合标签、合并行、帮助/错误提示可自然增高，不固定裁切。隐藏测量行保持0px。数字、日期使用等宽数字。树形缩进、固定列、拖动手柄不变。甘特条20px、里程碑菱形14px、时间轴比例保留。

## 布局与表单间距

- 顶栏总高50px，桌面左右32px，主导航与品牌间20px；保留原图标、文字和顶栏渐变，渐变端点尚未实测。
- 页面背景采用 `#F1EEFF → #ECF6FF`，90度角为工程建议。桌面外侧32px；窄屏沿用16px，导航允许横向滚动，品牌名不换行。
- 内容容器白底、圆角16px、内边距12px、主内容组间距12px。主内容外卡采用 `0 0 20px rgba(211,208,255,.5)` 与主色顶部2px内强调线；不扩散到每个业务卡片。
- **表单行距统一12px、列距16px、标签到控件4px、相关分组间8px。** `Form.Item` 负责行距，嵌套布局不再叠加纵向 gutter；输入错误与帮助仍占用正常文档流并允许增高。
- 表单分组边框黑色12%、圆角6px；保留各业务原有列数。资源月度的横向字段采用16px间距。
- 弹窗与抽屉主体左右24px；操作区最小64px、左右24px、按钮间16px，底角12px。复杂表单内部滚动；不把所有弹窗宽度改成1199px。
- 分页、筛选、字段配置、可编辑单元格及宽表横向滚动保留既有交互。

## 颜色与状态

- 实心主色 `#4D41FF`；次按钮 `#F0EFFF`。白色内容区，主要表格文字黑色，表格底边黑色3%。禁用与危险按钮保留语义。
- 中性标签 `#F2F2F2/#808080`，进行中/修改 `#EBF3FF/#0A69FE`，成功/新增 `#EBFAF2/#14C764`，删除 `#FFEBEB/#FF3430`。中性、成功、危险文本使用可读深色，是工程补全；警告沿用既有语义。
- 去除数据容器的悬浮位移、呼吸光和主按钮渐变。实际可点击控件保留背景/边框反馈和键盘焦点。
- 异常浅红底、红色图标、修订中浅黄底、取消/锁定/选中态及权限必须保留，不以统一颜色覆盖。

## 执行与验收

所有模块共用 `src/theme/pmsTheme.ts`、`src/styles/globals.css`，`html[data-ui="figma-pms"]` 让门户弹层继承变量。覆盖工作台、项目管理/配置、列表/卡片/日历、组合管理、项目空间/计划/资源/权限/转维、HR四类投入与配置、路标、独立模板与分享路由、弹窗/抽屉。

验收需在1440×900主视口及1280×800、1920×1080检查，包含只读/编辑/错误/低高度弹窗状态。实测值与工程补全的边界、旧新映射和验证记录见 [implementation.md](../design/figma-pms-20260920/implementation.md)。
