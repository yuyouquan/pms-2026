# 权限中心筛选条件面板验收

## 行为

- 顶部固定显示条件匹配方式、条件数量、字段搜索和添加按钮。
- 新增条件插在第一条；清空搜索并将内部列表滚回顶部。
- 字段搜索仅过滤当前展示的条件，编辑和删除仍按原条件 ID 操作完整草稿，避免隐藏条件被删除。
- 条件列表内部滚动。桌面弹窗移除默认定位间距并随内容变化重新定位；窄屏或矮屏固定在视口右上角，避免入口滚出屏幕后弹窗也跟着消失。
- 保留自动保存及未完成草稿保护机制。

## 验证

- `npm run build`、`npx tsc --noEmit`、`git diff --check` 通过。
- `verify-permission-center-inactive-conditions.mjs`、`verify-permission-center-corruption.mjs`、`verify-project-type-data-permissions.mjs`、`verify-permission-column-units.mjs` 通过。
- 浏览器连续新增，条件数量逐条从 1 增至 12。新条件位于顶部，旧条件索引后移；滚到底部再添加，scrollTop 恢复 0。
- 搜索“品牌”仅显示原有品牌条件；在存在其他未完成草稿时修改该值，已生效条件保持原值。搜索不存在字段显示空态，再添加时搜索清空、完整列表恢复。
- 1280×720 视口：12 条条件，弹窗矩形 [760, 0, 1214, 612]；内部列表高 438px、内容高 1060px。
- 820×480 视口：弹窗矩形 [349, 12, 803, 448]。
- 560×400 视口：弹窗矩形 [89, 12, 543, 368]；搜索和添加仍可操作。
- 草稿状态切换项目类型触发离开确认；确认丢弃后恢复原已保存权限。临时 localhost 测试授权恢复，127.0.0.1 独立 Mock 会话的草稿已丢弃，视口已重置。
- 最终浏览器 warning/error 日志为空。独立代码复核无待修复问题。

验收发现并修复了 rc-trigger 的两种边界情况：内容增长后需重新定位；入口在响应式布局下滚出视口时需避免继续依附该入口定位。
