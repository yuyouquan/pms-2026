# 项目视图按项目类型配置数据权限验收

## 范围

- 权限中心 → 数据权限 → 项目视图增加整机产品项目、tOS版本项目、技术项目、能力建设项目四个入口。
- 技术项目分别配置 TDT 项目和子项目。列设置直接复用对应项目列表的字段定义、顺序和必要列，技术节点取当前已发布模板，旧版本节点不会进入列设置。
- 能力建设项目按用户确认保留“暂无可配置列”，不新增列或筛选编辑器。
- 各类型筛选/列设置独立实时保存，功能权限仍由项目视图菜单统一控制。未单独配置的类型继承原有效规则，保留原授权边界。
- 人员视图同步显示所选类型的有效规则；内置系统超级管理员保持全权限、不可编辑。

## 修复的边界问题

- 仅授权技术子项目时，分类入口与点击不能继续用被拒绝的父 TDT 数据规则拦截；分类仅使用已授权行作为来源，父项目本身仍不获得授权，空间进入校验继续保留。
- 旧 `name` 条件继续读取父项目名称；新 `projectName` 条件可读取实际列表中的子项目名称，避免改变旧规则导致权限放宽。
- 权限受限项目卡片的辅助标签不再显示未授权的项目名称。
