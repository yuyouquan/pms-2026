# 资源版本激活与里程碑居中回归

范围：版本激活/取消激活状态、跨页面持久化、正式项目和预算项目里程碑日期居中。基线 feature `59a2ae7`。

## 调查结论

- 里程碑父级 `dd` 的文字已经居中，但子级行内控件是 flex，默认从左开始布局。增加控件容器的 `justify-content: center`，同时居中日期编辑器输入；适用于只读、点击编辑展示态和编辑态。
- 当前基线已经包含 `59ab48b`：只持久化人力业务数据，并避免无变化刷新触发写入，解决跨标签页存储循环覆盖状态。此轮未复现额外的激活状态转换错误，不对正常激活语义作推测性改动。
- 增加真实 Workspace 回调与真实 Zustand store 的生命周期回归，以及四类项目、三类预算的双向跨页激活/取消同步断言。回调脚本使用轻量 React/AntD 渲染替身，不能替代浏览器测试。
- 首轮回归发现导入测试脚本未解析新增 helper 的 `@/` 路径。修正测试加载器以加载真实模块，业务导入逻辑未修改。
