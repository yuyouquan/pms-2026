# 资源版本按钮和操作日志回归

## 调整

- 版本删除按钮与锁定、正式版本、导出采用相同的 32px 无边框图标样式；悬停或键盘聚焦时显示危险色，保留删除确认及权限检查。
- 移除版本信息栏内的“版本操作日志”，保留版本 Tab 右侧唯一“查看操作日志”入口，默认查看当前预算分类的全部版本。
- 日志继续记录创建、复制、删除、各版本字段/部门/非人力/月度人力修改、锁定与正式版本变更；可搜索并按版本筛选，删除的版本仍可筛选。
- 修复历史版本只有临时创建记录时，删除后创建记录丢失的问题：首次有效操作时按原创建人/时间/版本号补存一次。无变化保存、自动刷新和水合不新增操作记录。
- 日志弹窗去除叠加的顶边距，标题分隔线至筛选栏保留 16px。

## 自动验证（通过）

- `npm run verify:resource-logs`：时间排序、分页、搜索、筛选、展开与只读展示。
- `npm run verify:resource-formal`：四类项目创建/修改/删除日志持久化；旧版本创建信息在直接删除后保留且不重复。
- `npm run verify:resource-versions`：版本生命周期、复制、锁定、独立持久化。
- `npm run verify:resource-inline`：行内编辑、自动保存和输入取消。
- `npm run verify:resource-permissions`：唯一日志入口、全部版本默认范围、删除后入口保留、权限变更重新检查。
- `npm run verify:resource-cross-tab`：跨标签页日志与数据原子同步。
- `npx tsc --noEmit`、`npm run build`、`git diff --check`。
