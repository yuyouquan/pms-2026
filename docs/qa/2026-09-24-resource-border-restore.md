# 资源版本页恢复线框版

## 范围

按用户确认，年度预算、项目概算、项目预算恢复到去线框前的界面（基准 `00c0f8a`），包括卡片、版本栏、里程碑、表格和输入控件的原有样式。总览保留本轮优化样式。

资源详情结构与基准一致，仅保留随后明确要求的「技术项目隐藏顶部排布工具栏」条件。计算、权限、保存及已有数据不回退。

## 验证

- 原有公共 CSS 与基准内容完全一致；总览覆盖样式仅在总览页启用。
- `npm run verify:resource-inline`、`npm run verify:resource-dashboard`、`npm run verify:liquid-glass`：通过。
- `npx tsc --noEmit`、`npm run build`、`git diff --check`：通过。
- 本地生产构建浏览器：三个版本页均恢复 1px 卡片边框；里程碑与可编辑控件边框恢复；新增分区标题及灰色画布已撤回。
- 1280px 同宽对比：总览容器、筛选、指标卡、内容区、表头的计算样式与发布前一致。
- 等级系数编辑按 Escape 取消、人力/非人力切换正常；技术预算排布按钮为 0，九个里程碑输入保留。
- 生产构建页面没有浏览器运行时错误。开发服务器首次加载曾出现旧开发资源解析错误，改用干净生产构建验证后未复现。

发布后核验远端 feature/dev/master 内容与 Vercel 正式部署，截图及结果保存在当前任务 `resource-border-restore-20260924` 证据目录。
