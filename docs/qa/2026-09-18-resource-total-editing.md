# 资源整格编辑与投入合计分配验收

## 范围与计算口径

本轮六项：整格编辑、版本状态图标、后续阶段文案、投入表居中、人力总额按阶段分配、非人力总额按月份平摊。

人力默认以当前已保存里程碑日期的阶段间隔计算权重，覆盖表格展示的阶段和后续阶段；不加首尾重复日。人力按 0.1 人月、费用按 0.01 元对齐尾差。用户尚未选择模型比例；如改为模型，需要更换权重来源并重新分配。原计划模板占比规则保持不变。

### 实现决策

- 人力按当前保存的阶段天数比例分配，含后续阶段；若后续决定使用模型比例，需要改权重来源并重新分配。
- 整机已手工填写的实际投入不会因模型或系数元数据变化被覆盖，旧编辑预览也明确提示保留；重新套用模型需另行定义入口。
