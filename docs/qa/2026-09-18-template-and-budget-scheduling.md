# 计划模板间隔与预算里程碑排布验收

## 范围与计算约定

- 一级计划、TDT项目计划增加间隔天数、占比和总周期，移除角色显示；子项目计划与 MR 保持原契约。
- 预算资源两个输入都是计划完成时间：整机“概念启动 / STR5”、tOS“规划KO / STR5”、技术“规划启动 / EDCP”。
- 自动排布使用最新已发布模板，随资源版本保存模型快照；模板草稿需先发布。
- 间隔归属于到达该里程碑的时间段，首锚点之前没有区间，因此首锚点的间隔不参与所选窗口内的分配。
- 固定两个端点，按间隔权重分配中间完成日期；手动改日期重新计算排布指标，不修改模型。
