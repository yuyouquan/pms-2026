# 项目资源版本行内编辑验收

## 范围与判定

项目空间资源中的年度预算、项目概算、项目预算。新建后直接进入已保存的详情；字段的编辑图标启用局部输入；点击其他位置自动保存并恢复文字。既有版本复制、激活、锁定规则不变。项目资源看板、项目核算保留空页。

## 基线

- 起点提交：`c51e61d`，独立工作区 `feature-project-auto-scheduling`，主工作区未改动。
- 实际浏览器旧版整机示例 `DEMO017-DEMOCHIP001_DEMOBOARD016` 显示 V0.3、等级系数 1.30、预估与月度合计均 130.0 人月；仍有“编辑版本”，批次一直处于下拉输入状态。
- 既有业务约束：整机部门投入由模型计算；正式项目来源字段只读；tOS 的上市迭代结束、维护结束手工维护；能力建设开始/结束时间手工维护。非人力单位为元。

- `cf7d804` 修复 Escape 和异步导入生命周期：组件卸载、切换版本、后续编辑或锁定后，旧文件读取/旧确认不再写回。新增测试执行实际组件回调，覆盖延迟读文件和确认对话框。
